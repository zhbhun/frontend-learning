# Lottie（Web 动画）

- [@官方@airbnb/lottie-web](https://github.com/airbnb/lottie-web)
  覆盖：lottie-web 运行时官方仓库，README 即主文档——引入方式、三种渲染器、loadAnimation 全部选项、播放控制与事件 API。适用于：几乎所有课程的一手依据。
- [@官方@Lottie 格式文档（lottie-docs）](https://lottiefiles.github.io/lottie-docs/)
  覆盖：Lottie JSON 格式规范总入口——数据结构、图层、形状、资源、表达式，附 JSON 编辑器与 builder 两个 Playground。适用于：JSON 结构概览课与字段排错。
- [@官方@Lottie Specs（Lottie Animation Community）](https://lottie.github.io)
  覆盖：Linux Foundation 旗下的开放规范组织：机器可读的 JSON Schema、规范讨论与演进路线图。适用于：格式概览课的权威对照与版本演进背景。
- [@官方@LottieFiles 开发者文档](https://docs.lottiefiles.com)
  覆盖：LottieFiles 生态开发者工具与库的文档总站（播放器、交互库、dotLottie 工具链）。适用于：生态与播放器课程。
- [@官方@dotLottie](https://dotlottie.io)
  覆盖：.lottie 打包格式的官方站点：格式动机、打包规范、生态状态。适用于：dotLottie 与新一代运行时课程。
- [@官方@dotlottie-web](https://github.com/lottiefiles/dotlottie-web)
  覆盖：Rust + WASM 高性能运行时官方仓库，提供 Web Components（`@lottiefiles/dotlottie-wc`）与 React/Vue/Svelte 封装；已归档的 lottie-player 的官方继任者。适用于：播放器与生态课程、进阶集成。
- [@官方@bodymovin（aescripts）](https://aescripts.com/bodymovin/)
  覆盖：After Effects 导出插件的官方分发页与版本说明。适用于：制作流程课。
