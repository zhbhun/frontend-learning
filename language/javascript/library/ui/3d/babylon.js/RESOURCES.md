  覆盖：安装、引擎与场景、相机、光照、材质、纹理、模型、动画、交互、GUI、物理和进阶主题的完整文档站。适用于：所有课程主线；具体章节链接见对应课程的参考资料。

  覆盖：全部类、构造参数、属性、方法和模块导入路径。适用于：所有课程的 API 查证；具体 API 页链接见对应课程的参考资料。
- [@官方@Babylon.js Guided Learning](https://doc.babylonjs.com/guidedLearning/)
  覆盖：从基础概念到相机、光照、材质、动画、模型加载和交互的官方分步教程。适用于：第一阶段和第二阶段课程主线，以及概念补充。
- [@官方@Babylon.js Playground](https://playground.babylonjs.com/)

- [@开源@Babylon.js GitHub repository](https://github.com/BabylonJS/Babylon.js/)
  覆盖：源码、包目录、devCore、issue 和项目结构。适用于：理解 `@babylonjs/core` 等包、排查版本差异、阅读实现。
- [@开源@Babylon.js Releases](https://github.com/BabylonJS/Babylon.js/releases)
  覆盖：版本发布记录和破坏性变化。适用于：长期学习时确认 API 变化和示例代码适配。

## 社区

- [Babylon.js Forum](https://forum.babylonjs.org/)
  适用于：真实项目问题、版本变化、模型加载、性能、材质、WebGPU 和官方团队反馈。
- [Stack Overflow: babylon.js](https://stackoverflow.com/questions/tagged/babylon.js)
  适用于：明确报错、API 用法和历史问题检索；答案需要结合当前 Babylon.js 版本复核。
- [r/BabylonJS](https://www.reddit.com/r/BabylonJS/)
  适用于：作品灵感、生态动态和非正式经验；不作为课程事实依据的主要来源。

## 工具

- [@官方@Babylon.js Inspector](https://doc.babylonjs.com/toolsAndResources/inspectorLayerExtension/)
  覆盖：内置调试面板，可查看场景树、属性、纹理、性能和后处理。适用于：调试课程和所有课程的排查入口。
- [@官方@Node Material Editor](https://nme.babylonjs.com/)
  覆盖：可视化节点编辑器，连线组合材质与着色器。适用于：Node Material、Shader 和进阶渲染课程。
- [@官方@Babylon.js Sandbox](https://sandbox.babylonjs.com/)
  覆盖：在线模型查看器和 Inspector，加载 glTF/GLB/.babylon 并即时检查。适用于：模型加载、材质和调试课程。
