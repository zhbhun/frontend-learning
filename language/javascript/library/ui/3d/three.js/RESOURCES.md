# Three.js

- [@官方@three.js official site](https://threejs.org/)
  覆盖：three.js 当前入口、文档、示例、编辑器、DevTools、社区和下载。适用于：所有阶段的官方入口和版本状态确认。
- [@官方@three.js Manual](https://threejs.org/manual/)
  覆盖：安装、创建场景、文本、线条、纹理、材质、光照、相机、响应式渲染、模型加载、优化等入门到中级主题。适用于：第一阶段和第二阶段课程主线；具体章节链接见对应课程的参考资料。
- [@官方@three.js Docs](https://threejs.org/docs/)
  覆盖：全部 API 类、构造参数、属性、方法和模块导入路径。适用于：所有课程的 API 查证；具体 API 页链接见对应课程的参考资料。
- [@官方@three.js Examples](https://threejs.org/examples/)
  覆盖：官方可运行示例，包含 controls、loaders、materials、textures、shaders、postprocessing、WebGL/WebGPU 等。适用于：临摹、拆解和扩展练习；具体示例链接见对应课程的参考资料。
- [@开源@three.js GitHub repository](https://github.com/mrdoob/three.js/)
  覆盖：源码、示例源码、addons、issue、wiki 和项目结构。适用于：理解 `examples/jsm`、排查版本差异、阅读实现。
- [@官方@three.js Releases](https://github.com/mrdoob/three.js/releases)
  覆盖：版本发布记录。适用于：长期学习时确认 API 变化和示例代码适配。
- [@官方@three.js Migration Guide](https://github.com/mrdoob/three.js/wiki/Migration-Guide)
  覆盖：升级 three.js 版本时的破坏性变化、弃用和迁移建议。适用于：维护旧项目和识别教程过时点。

## 社区

- [three.js forum](https://discourse.threejs.org/)
  适用于：真实项目问题、版本变化、模型加载、性能、材质、WebGPU 和社区经验判断。
- [three.js Discord](https://discord.gg/56GBJwAnUS)
  适用于：快速交流、近期生态经验和方向验证。
- [Stack Overflow: three.js](https://stackoverflow.com/questions/tagged/three.js)
  适用于：明确报错、API 用法和历史问题检索；答案需要结合当前 three.js 版本复核。
- [r/threejs](https://www.reddit.com/r/threejs/)
  适用于：作品灵感、生态动态和非正式经验；不作为课程事实依据的主要来源。

## 教程

- [@书籍@Discover three.js](https://discoverthreejs.com/book/)
  覆盖：从基础概念到相机、光照、材质、纹理、动画、模型加载和项目结构的系统教程。适用于：作为官方 Manual 之外的中文课程设计参考和概念补充。
- [@课程@Three.js Fundamentals](https://threejsfundamentals.org/)
  覆盖：基础对象关系、渲染循环和常见概念解释的系列教程。适用于：当官方 Manual 解释不够细时作为补充练习。
- [@课程@Three.js 系列教程](https://github.com/puxiao/threejs-tutorial)
  覆盖：中文 three.js 教程和示例。适用于：中文辅助阅读；使用前需要对照官方文档检查版本差异。
- [@课程@Three.js Journey](https://threejs-journey.com/)
  覆盖：系统化项目式 three.js 课程，包含基础、材质、3D text、shader、后处理和项目实践。适用于：可选付费实践资源，不作为本学习路线的必要依赖。
