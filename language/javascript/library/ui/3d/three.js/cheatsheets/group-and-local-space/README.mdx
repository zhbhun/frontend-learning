# Group

`THREE.Group` 是 `Object3D` 的子类，但它本身不参与渲染——既没有 geometry，也没有 material。它充当一个透明容器：用 `group.add(mesh)` 把多个对象挂进来后，这些对象共享 Group 的局部坐标系，对 Group 的 `position`、`rotation`、`scale` 会作为父级变换传给全部后代。

把多个对象挂进 Group 等于声明“它们属于同一组”。整组平移、旋转或缩放只需改 Group 的 TRS，子对象之间的相对布局由它们各自的局部 TRS 决定，不会因为 Group 移动而错位。相比之下，把一组 Mesh 放进普通数组再逐个加同样的增量，既容易漏掉对象，又绕开了 three.js 的父级矩阵机制，每帧还要自己同步坐标。Group 沿用 Object3D 的全部变换与层级规则，本课只展开它作为容器的独特用途；通用的局部/世界变换、矩阵更新时机见 [Object3D](?path=/docs/object3d-transform-hierarchy--docs)。

## 快速上手

创建 Group，把多个 Mesh `add` 进去，然后只变换 Group：

```js
const group = new THREE.Group();
group.position.set(0, 0.7, 0);
scene.add(group);

const offsets = [
  new THREE.Vector3(-2, 0, 0),
  new THREE.Vector3(2, 0, 0),
  new THREE.Vector3(0, 0, -2),
  new THREE.Vector3(0, 0, 2)
];

offsets.forEach((offset, index) => {
  const mesh = new THREE.Mesh(geometry, materials[index]);
  mesh.position.copy(offset); // 相对 group 的局部坐标
  group.add(mesh);
});

group.rotation.y = Math.PI / 4; // 整组绕 group 原点旋转，子对象相对布局保持
```

| 输入或状态 | 默认值 / 常用起点 | 改变后要注意什么 |
| --- | --- | --- |
| `new THREE.Group()` | 空容器，无 geometry / material | 自身不会被渲染；只把变换和可见性传给子树 |
| 子对象 `position` | `(0, 0, 0)` | 是相对 Group 局部空间的坐标；移动 Group 后子对象局部值不变 |
| `group.position` / `rotation` / `scale` | Object3D 默认值 | 整体作用于全部后代；非均匀缩放会影响子对象位置和方向 |
| `group.visible` | `true` | 设为 `false` 会隐藏整棵子树 |
| `group.renderOrder` | `0` | 影响整组在透明排序中的相对顺序 |
| 嵌套 Group | 任意层级 | 每一级 TRS 都会沿父级链累乘到后代 |

## 整体变换与各自变换

把对象放进 Group 后，旋转 Group 与旋转每个子对象是两种不同的操作：

- 旋转 Group 时，Group 把它的旋转作为父级变换传给子级；子对象的局部 `position` 不变，但世界位置会绕 Group 原点旋转，整组保持原有布局整体转动。
- 各自旋转每个 Mesh 时，每个子对象只绕自身中心旋转，世界位置不变。

下面的实例把四个立方体摆成十字放进同一个 Group。切换“旋转 Group”“各自旋转”“同时旋转”，观察读数中采样 Mesh 的局部 position 与世界 position：Group 旋转时局部值始终是 `(-2.00, 0.00, 0.00)` 而世界值绕原点连续变化；各自旋转时世界位置基本固定，只有“自身旋转 Y”在变。

## 局部坐标系

Group 的 `position`、`rotation`、`scale` 描述它自身相对父级的局部变换；同时它给所有子对象提供一个新参考系。子对象的 `position` 总是相对最近的父级——把对象从 `scene` 移到 `group` 后，同一个 `(2, 0, 0)` 不再表示世界 X 方向 2 个单位，而表示 Group 局部 X 方向 2 个单位。

```js
// 子对象在 group 局部空间里以 group 原点为参考摆放
wheel.position.set(1.2, -0.3, 0.8);
carGroup.add(wheel);

// 移动 carGroup 时，车轮、车身、车灯一起平移；轮子的局部 position 不变
carGroup.position.set(0, 0.5, 0);
carGroup.rotation.y = Math.PI / 2;
```

相对布局一旦摆好，整组可以在场景里任意摆放、旋转、缩放，子对象之间的相对关系不会变。读取子对象的最终落点要用世界坐标：先确保矩阵链有效，再 `getWorldPosition(target)`；改了 `matrixAutoUpdate` 的对象还要先 `updateMatrix()`，详见 [Object3D](?path=/docs/object3d-transform-hierarchy--docs)。

## 组合多部件与相对动画

Group 最常见的用途是把多部件模型组织成一个整体，让“整组在世界中的运动”与“部件相对自身的运动”互不干扰。

- 一辆车由车身、四个车轮、车灯组成；车身和车轮都挂进 `carGroup`，移动 `carGroup` 让整车前进，再单独驱动每个车轮绕自身轴旋转。
- 一只机械臂由底座、大臂、小臂、末端工具组成；每一节是上一级的子 Group，关节旋转沿父级链累乘。
- 行星系统：太阳是 `solarGroup` 的子对象，`earthOrbit` Group 自身绕太阳旋转，地球挂在 `earthOrbit` 下再绕它的局部原点自转。

```js
const car = new THREE.Group();
const body = new THREE.Mesh(bodyGeometry, bodyMaterial);
car.add(body);

const wheelOffsets = [
  [ 1.2, -0.3,  1.1], [ 1.2, -0.3, -1.1],
  [-1.2, -0.3,  1.1], [-1.2, -0.3, -1.1]
];
const wheels = wheelOffsets.map((offset) => {
  const wheel = new THREE.Mesh(wheelGeometry, wheelMaterial);
  wheel.position.set(...offset);
  car.add(wheel);
  return wheel;
});

scene.add(car);

renderer.setAnimationLoop((time) => {
  const delta = clock.getDelta();
  car.position.x += delta * forwardSpeed;          // Group 负责“整车前进”
  wheels.forEach((wheel) => {                      // Mesh 负责“绕自身轴自转”
    wheel.rotation.x += delta * spinSpeed;
  });
  renderer.render(scene, camera);
});
```

这里 Group 负责“整车在世界中的位置和朝向”，单个车轮 Mesh 负责“绕自身轴自转”，两种动画互不干扰，也不需要每帧重新计算每个部件的世界坐标。

## 嵌套与层级调试

Group 可以嵌套，每一级都是一个独立的局部空间。父级旋转或缩放会沿链累乘到所有后代，所以复杂的关节模型（机械臂、骨骼、行星系）通常用嵌套 Group 表达。

```js
const armBase = new THREE.Group();          // 底座，决定整机位置
const upperArm = new THREE.Group();         // 大臂，绕底座顶端旋转
const lowerArm = new THREE.Group();         // 小臂，绕大臂顶端旋转

upperArm.position.set(0, 1.2, 0);
lowerArm.position.set(0, 1.0, 0);

armBase.add(upperArm);
upperArm.add(lowerArm);
scene.add(armBase);

upperArm.rotation.x = Math.PI / 6;   // 大臂前后摆
lowerArm.rotation.x = -Math.PI / 4;  // 小臂相对大臂弯曲
```

调试层级时常用三种工具：

| 工具 | 用途 | 注意 |
| --- | --- | --- |
| `AxesHelper(size)` | 显示某一级 Group 的局部坐标轴方向 | 加到 group 后跟随它一起旋转，能直接看出局部轴朝哪 |
| `BoxHelper(object)` | 在世界空间画对象的 AABB | 父级变换后需要 `update()` 或重新加 |
| `traverse(callback)` | 深度优先访问自身与全部后代 | 遍历中不要修改场景树 |

按名称查找或批量设置：

```js
const wheel = car.getObjectByName('frontLeftWheel');
car.traverse((child) => {
  if (child.isMesh) child.castShadow = true;
});
```

`name` 由应用自己维护，不保证唯一；多个对象同名时 `getObjectByName()` 返回第一个匹配。

## 跨 Group 移动对象

`add()` 和 `attach()` 都能把对象挂到新 Group 下，但保留的状态不同：

```js
newGroup.add(object);    // 保留对象局部 TRS，世界外观可能跳变
newGroup.attach(object); // 重算局部 TRS，尽量保持世界外观
```

把对象从“红队”Group 移到“蓝队”Group 时，如果想让它停在原地只换归属，用 `attach()`；如果是重新摆放，用 `add()` 并手动设置新的局部 TRS。`attach()` 不支持新父级链中存在非均匀缩放的情况——更多边界（`add` 触发的事件、`attach` 的限制、矩阵更新时机）在 [Object3D](?path=/docs/object3d-transform-hierarchy--docs) 中展开。

## 最佳实践

- 把“逻辑上属于一组”的对象放进同一个 Group，让整体变换由父级矩阵负责，不要每帧同步多个对象的同一增量。
- 用嵌套 Group 表达真实的关节关系（车-轮、机械臂、太阳系），每一级只关心自己负责的旋转或平移。
- 子对象的 `position` 一律按局部坐标摆放，整组放在哪里由 Group 自身的 TRS 决定。
- 调试层级时优先用 `AxesHelper` 挂到可疑 Group，肉眼确认局部轴方向；不要靠读 `quaternion` 数值排查朝向。
- 把 Group 当作逻辑边界：需要批量隐藏、批量销毁或批量复制时，整组处理比按名称收集更稳。
- 释放时遍历整组对象分别 `dispose()` 它们的 geometry 和 material；`group.clear()` 只解除关系，不释放 GPU 资源。

## 常见问题

- 为什么旋转 Group 后子对象的位置看起来不对？
  子对象的 `position` 是相对 Group 的局部值；读取最终落点用 `getWorldPosition()`，或检查 Group 与祖先的 TRS。
- 为什么把对象 `add` 到新 Group 后画面跳了一下？
  `add()` 保留局部 TRS；如果新 Group 与旧 Group 的世界变换不同，子对象在世界中会跳到新位置。要保持世界外观使用 `attach()`。
- Group 的 `visible` 设为 `false` 后还在画？
  `visible` 控制整棵子树是否参与渲染；若仍能看到对象，检查该对象是否同时挂在其他可见 Group 下，或代码里在别处又把它 `visible = true`。
- 为什么 `castShadow` 设置后整组没阴影？
  `castShadow` 是逐对象属性，不会从 Group 继承；要批量开启需用 `traverse` 遍历设置。
- 旋转 Group 时子对象的世界位置没更新？
  renderer 默认每帧自动更新世界矩阵；若关闭了 `matrixAutoUpdate` 或 `matrixWorldAutoUpdate`，要手动调用 `updateMatrixWorld()`，详见 [Object3D](?path=/docs/object3d-transform-hierarchy--docs)。

## 总结回顾

摘要：

Group 是不参与渲染的 Object3D 容器，用来用局部坐标组织多个对象。子对象的 position、rotation、scale 相对 Group 摆放，对 Group 的变换沿父级链传给整组，因此可以一次性整体平移、旋转或缩放而不破坏子对象之间的相对布局。嵌套 Group 形成多级局部空间，是组合多部件模型、相对动画和关节系统的常用结构。

一句话：

> 想让一组对象一起动又保持相对关系，把它们挂进 Group，只变换 Group 本身。

知识要点：

- Group 与 Mesh 在渲染上有什么本质差别？
- 旋转 Group 时，子对象的局部 position 和世界 position 各自怎样变化？
- 什么时候用 Group 组织对象，而不是直接维护一个数组？
- 嵌套 Group 时每一级的局部坐标系如何叠加？
- 把对象从一个 Group 移到另一个 Group，`add()` 与 `attach()` 分别保留什么？
