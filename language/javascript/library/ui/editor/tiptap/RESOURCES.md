- [@官方@Tiptap 文档总站](https://tiptap.dev/docs)
  覆盖：Editor 全部概念的官方手册——安装、核心概念、命令与事件、扩展、自定义扩展、跨领域指南；付费产品线与 Hocuspocus、UI Components 文档也在同一站点。适用于：整个学习路线的主线资料，各课程按小节引用。

  覆盖：basics / advanced / experiments 三级可运行示例，含菜单、提及、表格、协作等真实场景。适用于：各课程范例设计与验证参考。

  覆盖：官方开源的 Yjs 协作后端，安装、鉴权、持久化与扩展点、部署。适用于：实时协作阶段的自托管后端课程。
