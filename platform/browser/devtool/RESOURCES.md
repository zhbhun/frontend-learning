# Chrome DevTools

- [@官方@Chrome DevTools 文档](https://developer.chrome.com/docs/devtools)
  覆盖：全部面板与能力的官方手册——DOM/CSS 检查、Console、Sources 调试、Network、Performance、Memory、Application、Lighthouse 等。适用于：所有课程的一手依据与回查入口。
- [@官方@What's new in DevTools](https://developer.chrome.com/docs/devtools/whats-new)
  覆盖：每月发布的新特性与界面变化。适用于：核对课程描述是否过时、跟进新能力。
- [@官方@Chrome DevTools Protocol](https://chromedevtools.github.io/devtools-protocol/)
  覆盖：CDP 各域（DOM、Network、Debugger、Profiler 等）的协议参考。适用于：协议与自动化课程。
- [@官方@Lighthouse 文档](https://developer.chrome.com/docs/lighthouse/overview/)
  覆盖：审计指标、评分权重、CLI 与编程集成。适用于：Lighthouse 审计课程。
- [@开源@devtools-frontend](https://github.com/ChromeDevTools/devtools-frontend)
  覆盖：DevTools 自身的开源仓库。适用于：确认某行为是 bug 还是设计、跟踪实验特性进展。

## 工具

- [eruda](https://github.com/liriliri/eruda)
  覆盖：移动端页面内调试控制台（Console、Elements、Network）。适用于：远程与移动端调试课程。
- [vConsole](https://github.com/Tencent/vConsole)
  覆盖：腾讯开源的移动端网页调试面板。适用于：远程与移动端调试课程，与 eruda 做选型对比。
- [PageSpy](https://github.com/HuolalaTech/page-spy-web)
  覆盖：远程实时调试平台，把多端运行数据汇总到 Web 控制台。适用于：真机与远程联调场景。
- [chrome-devtools-mcp](https://github.com/ChromeDevTools/chrome-devtools-mcp)
  覆盖：官方 MCP 服务器，让 AI Agent 通过 DevTools 检查与操控 Chrome。适用于：协议与自动化课程。
