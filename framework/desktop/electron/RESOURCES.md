# Electron

- [@官方@Electron 官方文档（含中文版）](https://www.electronjs.org/docs/latest)
  覆盖：全部核心 API、进程模型、安全指南与官方教程，文档内嵌可运行的 Fiddle 示例。适用于：所有课程的第一手依据。
- [@官方@Electron Forge](https://www.electronforge.io/)
  覆盖：脚手架、开发、构建、打包、签名、发布与自动更新的完整工具链文档。适用于：起步、工程化、打包与发布阶段。
- [@官方@Electron 博客与发布计划](https://www.electronjs.org/blog)
  覆盖：版本节奏、重要特性公告与破坏性变更，具体版本状态见 releases.electronjs.org。适用于：选择示例基准版本和升级判断。

## 社区

- [Electron Discord](https://discord.gg/electron)
  适用于：疑难问题的现实反馈与经验判断。

## 示例

- [@开源@electron-react-boilerplate](https://github.com/electron-react-boilerplate/electron-react-boilerplate)
  覆盖：React + Electron + 构建链的成熟工程组织方式。适用于：框架集成阶段的 React 工程结构参考。
- [@开源@Motrix](https://github.com/agalwood/Motrix)
  覆盖：真实世界 Electron 应用的完整实现（多窗口、托盘、任务调度、打包发布）。适用于：框架集成与进阶主题的真实应用拆解。

## 工具

- [@官方@Electron Fiddle](https://www.electronjs.org/fiddle)
  覆盖：官方沙盒程序，内置覆盖常用 API 的示例模板，可直接运行、分享（官方 API Demos 已归档，由此承接）。适用于：起步阶段与单点 API 快速验证。
- [@开源@electron-vite](https://github.com/alex8088/electron-vite)
  覆盖：面向 Electron 的 Vite 构建封装，统一主进程、预加载、渲染三端构建。适用于：工程化与框架集成课程的 TS + Vite 基座。
- [@开源@electron-builder](https://github.com/electron-userland/electron-builder)
  覆盖：Forge 之外的主流打包方案（多平台安装包、差分自动更新）。适用于：打包发布课程的替代方案对比。

## 资源

- [awesome-electron](https://github.com/sindresorhus/awesome-electron)
  覆盖：Electron 生态的工具、库与开源应用索引。适用于：为按需主题寻找候选库。
