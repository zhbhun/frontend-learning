# Tauri

- [@官方@Tauri 官方文档](https://tauri.app)
  覆盖：Tauri 2 完整体系——环境准备、核心开发（窗口、IPC、事件、资源）、插件、权限与安全、打包分发、移动端。适用于：几乎所有课程的第一参考，路线中每个节点都能在这里找到对应章节。
- [@官方@tauri-apps/tauri 源码仓库](https://github.com/tauri-apps/tauri)
  覆盖：框架本体源码、官方示例（仓库内 `examples/`）、issue 与路线。适用于：需要核对真实行为、查看 `examples/api` 可运行演示、判断特性是否落地时。
- [@官方@tauri crate API 文档（docs.rs）](https://docs.rs/tauri)
  覆盖：Rust 侧 `tauri` crate 的完整 API 参考。适用于：讲解命令、状态、窗口等 Rust 侧 API 的课程回查。
- [@官方@Tauri Blog](https://tauri.app/blog/)
  覆盖：版本发布公告、重大变更与迁移说明。适用于：确认版本差异（如 1.x→2.x）和新增特性时。
