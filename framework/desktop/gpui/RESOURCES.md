# GPUI

- [@官方@GPUI 官方站点](https://gpui.rs/)
  覆盖：框架定位、核心文档（README、Crate 根文档、Contexts、Key Dispatch）与精选示例导读。适用于：入门上手与各阶段课程的权威起点。
- [@官方@gpui API 参考（docs.rs）](https://docs.rs/gpui)
  覆盖：gpui crate 全量 API，含 prelude 与所有权数据流模块文档。适用于：所有课程的 API 核对与回查。
- [@开源@gpui 源码与官方示例仓库](https://github.com/zed-industries/zed/tree/main/crates/gpui)
  覆盖：框架源码、`docs/`（contexts.md、key_dispatch.md）与 `examples/` 下 40+ 个可运行示例。适用于：路线各节点都能找到对应官方示例对照。
- [@官方@gpui 版本记录（crates.io）](https://crates.io/crates/gpui)
  覆盖：各发布版本与依赖变化。适用于：确认课程编写时对应的 crate 版本。
