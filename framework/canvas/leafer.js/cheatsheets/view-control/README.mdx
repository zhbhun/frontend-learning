# 视图控制

视图控制改变的是「看内容的窗口」，而不是内容本身。在 LeaferJS 里，这个窗口由 `leafer.zoomLayer` 承担——它是一个隐藏在内容下方的变换层，记录着视图的偏移 `x / y` 与缩放 `scaleX / scaleY`。所有平移、缩放（无论手势、滚轮，还是代码调用）最终都是改写这一层的变换；内容节点的 `x / y / scale` 始终是它自己的本地值，不受视图影响。

把握这一点，就能预测三件事：

- **平移视图** 改的是 `zoomLayer.x / y`，内容节点的坐标不变；
- **缩放视图** 改的是 `zoomLayer.scaleX / scaleY`，可以绕指定点放大整个画面；
- **`leafer.zoom()`** 是 `@leafer-in/view` 提供的便捷方法，一次性把视图设到指定比例或自动 `fit` 到内容，省去手算偏移。

本课覆盖视图的平移与缩放：`zoomLayer` 这个底层入口、`@leafer-in/view` 的程序化 `zoom()` 方法、以及把指针 / 滚轮事件接到 `zoomLayer` 上做出可拖拽缩放画布的做法。元素的旋转 / 斜切属于单个节点的变换，不在「视图」范畴，见[变换](?path=/docs/transform--docs)一课。

## 关键入口与默认值

| 入口 | 作用 | 要点 |
| --- | --- | --- |
| `leafer.zoomLayer.x / y` | 视口偏移 | 直接读写即可平移，正值向右下 |
| `leafer.zoomLayer.scaleX / scaleY` | 视口缩放 | 两者保持一致即为等比缩放；改它要同步算偏移才能绕指定点缩放 |
| `leafer.zoom(type)` | 程序化缩放（`@leafer-in/view`） | `type` 可为数字、`'in'` / `'out'` / `'fit'` / `'fit-width'` / `'fit-height'` / 元素 / bounds |
| `zoom` config | 缩放范围与开关 | `disabled` 默认 `false`；`min` 默认 `0.01`、`max` 默认 `256`，`leafer.zoom()` 会按它钳制 |
| `move` config | 平移开关 | `disabled` 默认 `false`；`holdSpaceKey` / `holdMiddleKey` 默认 `true`（按住即拖动平移）；`drag` 默认 `false`（预览模式：拖动即平移、无法选元素） |
| `wheel` config | 滚轮行为 | `zoomMode` 默认 `false`（滚轮滚动平移），设 `true` 则滚轮直接缩放；`zoomSpeed` 默认 `0.5` |

`leafer.zoom()` 由 `@leafer-in/view` 装上，使用前需 `import '@leafer-in/view'`。

## 程序化缩放：leafer.zoom()

最直接的视图控制是 `leafer.zoom()`，引擎自动算好偏移，并按 `zoom.min / max` 钳制范围：

```ts
import { Leafer, Rect } from 'leafer-ui';
import '@leafer-in/view'; // 给 Leafer 装上 zoom() 方法

const leafer = new Leafer({ view, zoom: { min: 0.25, max: 4 } });
leafer.add(new Rect({ x: 100, y: 100, width: 200, height: 120, fill: '#4f7cff' }));

leafer.zoom(2);        // 数字：把视图缩放设为绝对值 2×（以画布中心为轴）
leafer.zoom('in');      // 放大一级（按 2 的幂次跳档）
leafer.zoom('out');     // 缩小一级
leafer.zoom('fit');     // 自动把所有内容居中适配到画布，默认留 30px 内边距
leafer.zoom(rect);      // 传元素 / 元素数组 / bounds：把它居中聚焦到视口
```

`zoomType` 的几类取值：`'in'` / `'out'`（按 2 的幂次跳档）、`'fit'`（整体适配）、`'fit-width'` / `'fit-height'`（按宽 / 高适配）、一个**绝对缩放数字**、一个或一组**元素**、或一个 **bounds** 区域。后两者适合「聚焦到某元素」，引擎自动算缩放与偏移。

`leafer.zoom()` 做的事，本质还是改写 `zoomLayer`：传入数字时，以画布中心为轴缩放 `zoomLayer`；传入区域时，把该区域平移并缩放到视口中央。理解了 `zoomLayer`，下面就能自己接交互。

## 平移与缩放的底层：zoomLayer

`leafer.zoom()` 解决「设到某个比例」，但很多场景需要跟着用户的手势走——拖一下平移、滚一下缩放。这些都要回到 `zoomLayer` 自己写：

- **平移** = 在指针移动时把位移累加进 `zoomLayer.x / y`；
- **缩放** = 改 `zoomLayer.scaleX / scaleY`，并同步调整 `x / y`，让光标下的内容点钉在原地（否则会「飘」）。

下面的实例就是这么做的。画布里有网格与若干图形，把指针 / 滚轮事件接到 `zoomLayer` 上，得到一个可拖拽缩放的设计画布。「拖拽平移」「滚轮缩放」两个开关控制是否响应；拖「视图缩放」滑块调用 `leafer.zoom(scale)`，「适应视图」调用 `leafer.zoom('fit')`。

以光标为中心缩放，关键是「缩放前后，光标下的世界坐标不变」——先把光标换算成世界坐标，缩放后再反算偏移：

```ts
const z = leafer.zoomLayer;
const factor = e.deltaY < 0 ? 1 + 0.15 : 1 / (1 + 0.15);
const newScale = clamp(z.scaleX * factor, MIN, MAX);
// 光标下的世界坐标（缩放前）
const wx = (cursorX - z.x) / z.scaleX;
const wy = (cursorY - z.y) / z.scaleY;
// 缩放后把同一个世界点钉回光标处
z.scaleX = z.scaleY = newScale;
z.x = cursorX - wx * newScale;
z.y = cursorY - wy * newScale;
```

这段就是实例里「滚轮缩放」handler 的核心。平移则更简单——`z.x += dx; z.y += dy`。把这两段接好，画布就具备了 Figma 式的拖拽平移与滚轮缩放。

## 交互开关与 config

LeaferJS 的 `move` / `zoom` / `wheel` 三段 config 描述了引擎对视图交互的配置：`move.drag` 是否允许拖拽平移、`wheel.zoomMode` 决定滚轮是缩放还是滚动、`zoom.min / max` 限定缩放范围。实例把「拖拽平移」「滚轮缩放」两个开关映射到这些语义——开 = 响应指针 / 滚轮并写入 `zoomLayer`，关 = 不响应。无论开关如何，最终改写的都是同一个 `zoomLayer`，这正是视图控制的统一入口。

把全部视图交互关掉、得到一个「纯绘图」画布，等价于建一个不含视图变换的 Leafer：

```ts
new Leafer({ view, type: 'draw' }); // 关闭缩放平移视图功能
```

也可以只关某一类：不接平移 handler 即关平移，不接滚轮 handler 即关滚轮，`zoom.disabled = true` 禁用缩放钳制外的捏合。

## 最佳实践

- **缩放范围按内容设。** 海量元素的大画布给较小的 `zoom.min`（如 `0.1`）；UI 类小画布给 `min: 0.5 / max: 3` 即可，避免无意义的极端缩放拖慢渲染。
- **聚焦元素用 `leafer.zoom(element)`。** 传元素或区域，引擎自动算缩放与偏移把它居中，比手算 `zoomLayer.x / y` 可靠。
- **滚轮缩放以光标为中心。** 直接改 `scaleX / scaleY` 会绕原点缩放，画面会「飘」；按上文公式同步算 `x / y`，让光标下的点不动，体验才自然。
- **改完 `zoomLayer` 记得同步布局。** 设值后世界矩阵不会立即重算，读坐标 / 包围盒前调一次 `leafer.updateLayout()`，保证读到最新变换（实例的 `syncReadout` 就是这么做的）。

## 常见问题

- **直接改了 `scaleX` 但视图「飘」走了。** 改缩放没同步改 `x / y`，导致绕原点而非光标缩放。按「以光标为中心」的公式先算世界坐标、缩放后再钉回。
- **`leafer.zoom is not a function`。** `zoom()` 是 `@leafer-in/view` 装上去的，需要 `import '@leafer-in/view'`；`leafer-ui` 默认导出不含这个方法。
- **读到的 `zoomLayer.x` 还是旧值。** 设值后世界矩阵未重算，读之前调 `leafer.updateLayout()`，或把读取放进 `leafer.nextRender(callback)`。
- **`zoom.min / max` 没起作用。** 范围只对 `leafer.zoom()`（经 `getValidScale` 钳制）生效；直接改 `zoomLayer.scaleX` 不会经过钳制，需自己在 handler 里 `clamp`。

## 总结回顾

摘要：

视图控制改的是 `leafer.zoomLayer` 这个「视口层」，而不是内容节点本身：平移改 `x / y`、缩放改 `scaleX / scaleY`。`@leafer-in/view` 给 Leafer 装上 `leafer.zoom()`，支持绝对数字、`'in' / 'out'` 跳档、`'fit'` 自动适配，以及聚焦到指定元素 / 区域，并按 `zoom.min / max` 钳制。要做可拖拽缩放的画布，把指针 / 滚轮事件接到 `zoomLayer`：平移累加 `x / y`，缩放按「光标下的世界坐标不变」同步算偏移。`move` / `zoom` / `wheel` 三段 config 是引擎对视图交互的开关描述，无论走哪条路，最终都落在同一个 `zoomLayer` 上。

一句话：

> 平移和缩放改的是 `zoomLayer`；`leafer.zoom()` 是程序化入口，接事件到 `zoomLayer` 是交互入口。

知识要点：

- 视图平移改 `zoomLayer` 的哪个属性？缩放呢？
- `leafer.zoom()` 的 `zoomType` 可以传哪几类值？
- 滚轮缩放如何做到「以光标为中心」而不是绕原点「飘」？
- `leafer.zoom()` 需要哪个插件？范围由哪段 config 钳制？
- 为什么改完 `zoomLayer` 后读坐标前要 `updateLayout()`？
