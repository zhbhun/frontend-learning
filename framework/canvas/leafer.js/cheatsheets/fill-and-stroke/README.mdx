# 填充与描边

填充（`fill`）画出图形的内部，描边（`stroke`）沿轮廓画出一条带宽度的边。两者是 `UI` 上**并行**的两道绘制工序：可以只填、只描，或同时使用。决定它们「画什么」的是同一套 **paint 表达**——纯色字符串、渐变对象、图案对象，`fill` 和 `stroke` 共用，区别只在于一个涂面、一个描边。

描边的可预测性集中在一点：**描边带相对 fill 边界的位置由 `strokeAlign` 决定**，而它的默认值随元素不同而不同——`Rect`/`Ellipse`/`Polygon`/`Star` 等 `UI` 基类图形默认 `inside`（描边整条落在填充内侧），`Line`/`Path` 默认 `center`（跨边界居中），`Text` 默认 `outside`（整条落在外侧）。一旦记住这条规则，就能预测「为什么我的矩形描边把填充盖住了一半」——它默认画在里面。

| 关键输入 | 默认 | 含义与回查要点 |
| --- | --- | --- |
| `fill` | 无（透明） | 填充画法：字符串、paint 对象或它们的数组。不设则内部透明。 |
| `stroke` / `strokeWidth` | 无 / 1 | 描边画法与粗细。**两者同时设置才画描边**，任一缺失都不画。 |
| `strokeAlign` | inside（UI）/ center（Line、Path）/ outside（Text） | 描边带相对 fill 边界的位置：inside 整条在内、center 跨边居中、outside 整条在外。 |
| `strokeCap` | `none` | 线帽：`none`（平帽，引擎内部映射为原生 `butt`）、`round`、`square`。作用于开放端点与每个 dash 两端。 |
| `strokeJoin` | `miter` | 拐角连接：`miter`（尖角）、`round`（圆角）、`bevel`（斜角）。 |
| `miterLimit` | 10 | `miter` 尖角的最大长度倍数（相对 `strokeWidth`），超过自动转 `bevel`。 |
| `dashPattern` | 不设（实线） | 虚线节律 `number[]`，如 `[8, 4]` = 画 8 空 4，可循环更复杂的节律。 |
| `dashOffset` | 0 | 虚线沿路径的起点偏移；负值反向。 |
| 线性渐变 `from` / `to` | `top` / `bottom` | 渐变起止位置，用 `IAlign` 关键字（`top-left`、`center`、`bottom-right`…）或 `{x,y}` 比例点。 |
| 径向渐变 `from` / `to` | `center` / `bottom` | `from` 是圆心、`to` 决定半径（两点距离）；可设 `stretch` 拉伸。 |
| 图案 `mode` | `cover` | 图像填充模式：`cover`/`fit`/`stretch`/`clip`/`repeat`/`normal`；`repeat` 配合 `scale` 控制瓦片大小。 |

## 填充

`fill` 接受三种等价表达，统一描述「用什么涂这个面」：

- **纯色字符串**：`fill: '#32cd79'`，最常用。等价对象写法是 `{ type: 'solid', color: '#32cd79' }`。
- **渐变 / 图案对象**（paint）：`{ type: 'linear' | 'radial' | 'angular' | 'image', ... }`，用一个 `type` 字段选择画法。
- **数组**：`fill: [paint, paint, ...]`，多层 paint 从下往上叠加，后一个画在前面之上。

同一个 `type` 选择框架也适用于 `stroke`——把下文对象里的 `fill` 换成 `stroke` 即可描出渐变或图案的边。下面的实例用「填充类型」控件在纯色、线性、径向之间切换，对照左下角「填充」读数确认当前画法。

### 纯色填充

给 `fill` 一个颜色字符串即可。LeaferJS 的颜色字符串支持 `#rrggbb`、`#rgb`、`rgb()/rgba()`、`hsl()/hsla()` 与 CSS 命名色。

```ts
import { Leafer, Rect } from 'leafer-ui'

const leafer = new Leafer({ view: window })

new Rect({ width: 100, height: 100, fill: '#32cd79' })
// 等价的对象写法
new Rect({ width: 100, height: 100, fill: { type: 'solid', color: '#32cd79' } })
```

`fill` 不设时内部透明——这是「为什么我的矩形看不见」最常见的两个原因之一（另一个是线类图形忘记 `stroke`）。

### 线性渐变

线性渐变沿 `from` → `to` 的直线方向过渡，颜色由 `stops` 给出。`from`/`to` 接受 `IAlign` 关键字（`top-left`、`top`、`center`、`bottom-right`…），缺省是 `top` → `bottom`（顶到底）。`stops` 传字符串数组时引擎按 `i/(len-1)` 自动均分 offset；要非均匀过渡就写 `{ offset, color }`。

```ts
import { Leafer, Rect } from 'leafer-ui'

const leafer = new Leafer({ view: window })

// 最简：stops 传字符串数组，offset 自动均分
new Rect({
  width: 100, height: 100,
  fill: { type: 'linear', stops: ['#FF4B4B', '#FEB027'] },
})

// 对角方向 + 自定义 offset
new Rect({
  width: 100, height: 100,
  fill: {
    type: 'linear',
    from: 'top-left', to: 'bottom-right',
    stops: [
      { offset: 0, color: '#FEB027' },
      { offset: 1, color: '#79CB4D' },
    ],
  },
})
```

### 径向渐变

径向渐变以 `from` 为圆心、`from`→`to` 的距离为半径画一个圆，从内向外过渡。`from` 缺省 `center`、`to` 缺省 `bottom`；`stretch` 可在不同方向拉伸半径，形成椭圆渐变。

```ts
import { Leafer, Ellipse } from 'leafer-ui'

const leafer = new Leafer({ view: window })

new Ellipse({
  width: 100, height: 100,
  fill: {
    type: 'radial',
    from: 'center', to: 'bottom-right',
    stops: ['#4f7cff', '#1f8b5a'],
  },
})
```

> 还有一种 `type: 'angular'`（角度/锥形渐变）按围绕圆心的角度过渡，写法与线性类似，适合色环、仪表盘等场景。

### 图案填充

用 `{ type: 'image', url }` 把位图当作填充。`mode` 决定图像如何贴合图形：`cover`（铺满，默认）、`fit`（contain）、`stretch`（拉伸）、`clip`（裁剪）、`repeat`（平铺）。`repeat` 模式配合 `scale` 控制瓦片大小。

```ts
import { Leafer, Rect } from 'leafer-ui'

const leafer = new Leafer({ view: window })

// 铺满（默认 cover）
new Rect({ width: 100, height: 100, fill: { type: 'image', url: '/image/leafer.jpg' } })

// 平铺：mode='repeat'，scale 控制瓦片大小
new Rect({
  width: 100, height: 100,
  fill: { type: 'image', url: '/image/leafer.jpg', mode: 'repeat', scale: 0.2 },
})
```

图像填充依赖网络资源与跨域：本地资源、同域图片或 data URL 最稳；跨域图片需服务端配置 CORS，否则填充会失败。这也是本课实例只演示纯色与渐变、未把 image 列入控件的原因。

## 描边

描边是沿图形轮廓绘制一条带宽度的边，由 `stroke`（画法）与 `strokeWidth`（粗细）共同决定——**两者同时设置才会画**。描边同样接受 paint 表达，所以可以描渐变边、图案边，写法与 `fill` 完全一致。

描边带相对 fill 边界的位置由 `strokeAlign` 决定，这是理解描边视觉表现的关键：`inside` 把整条描边画在填充内侧（`UI` 基类图形的默认值）、`center` 跨边界居中（一半在内一半在外）、`outside` 把整条画在外侧。下面的实例用一个六边形集中演示填充与描边的协同，控件覆盖宽度、虚线、对齐、线帽与拐角。

### 描边对齐 strokeAlign

`strokeAlign` 决定宽度方向上描边带落在 fill 边界的哪一侧，是描边最容易「看不出为什么」的参数。三档行为固定：

- `inside`：整条描边落在填充**内侧**，不向外扩张包围盒。引擎通过裁剪到图形区域实现。
- `center`：描边跨边界**居中**，一半在内、一半在外，向外扩张包围盒 `strokeWidth/2`。这是 Canvas 原生 `stroke()` 的默认行为。
- `outside`：整条描边落在填充**外侧**，向外扩张包围盒 `strokeWidth`。

```ts
import { Leafer, Rect } from 'leafer-ui'

const leafer = new Leafer({ view: window })

// 显式指定对齐：UI 基类默认是 inside，想要跨边居中必须写出来
new Rect({ width: 100, height: 100, fill: '#32cd79', stroke: '#172033', strokeWidth: 8, strokeAlign: 'center' })
```

默认值因元素而异：`Rect`/`Ellipse`/`Polygon`/`Star` 等 `UI` 基类图形默认 `inside`，`Line`/`Path` 默认 `center`，`Text` 默认 `outside`。所以「矩形的描边把内容盖了」几乎都是因为它默认画在里面——想要居中描边就显式写 `strokeAlign: 'center'`。

### 线帽与拐角 strokeCap / strokeJoin

`strokeCap` 控制开放端点（以及每个 dash 两端）的封口形状：`none`（平帽，引擎内部映射为原生 `butt`）、`round`（圆帽）、`square`（方帽）。`strokeJoin` 控制两段描边在拐角处的连接：`miter`（尖角，默认）、`round`（圆角）、`bevel`（斜角）。

```ts
import { Leafer, Polygon } from 'leafer-ui'

const leafer = new Leafer({ view: window })

new Polygon({
  width: 100, height: 100, sides: 5,
  fill: '#32cd79', stroke: '#172033', strokeWidth: 6,
  strokeAlign: 'center', strokeJoin: 'round',
})
```

要点：闭合图形的**实线**描边没有开放端点，所以 `strokeCap` 在实线闭合图形上「看不到效果」——把 `dashPattern` 打开后，`strokeCap` 才作用在每个 dash 的两端（`round` 会让虚线变成一串胶囊）。`strokeJoin` 只在拐角处生效，把虚线设为 0 观察最清晰。

### 虚线 dashPattern / dashOffset

`dashPattern` 是一个 `number[]`，按「画、空、画、空…」循环描述节律，单位 px。`[8, 4]` 就是画 8 空 4；`[8, 4, 2, 4]` 可以画出长短交替的复杂虚线。不设 `dashPattern` 即实线。`dashOffset` 平移虚线沿路径的起点，常用于让虚线「流动」（配合动画）或对齐接缝。

```ts
import { Leafer, Rect } from 'leafer-ui'

const leafer = new Leafer({ view: window })

// 等距虚线
new Rect({ width: 200, height: 80, stroke: '#172033', strokeWidth: 4, dashPattern: [8, 4] })
// 长短交替 + 起点偏移
new Rect({ width: 200, height: 80, stroke: '#172033', strokeWidth: 4, dashPattern: [12, 4, 2, 4], dashOffset: 8 })
```

`dashOffset` 可为负值（反向偏移）。虚线配合 `strokeCap: 'round'` 会得到圆头 dash，是描边动画与点画线的常用组合。

## 最佳实践

- **要居中描边就显式写 `strokeAlign: 'center'`。** `UI` 基类图形默认 `inside`，描边会吃掉一层填充；只有显式指定才能让描边跨边界居中或画到外侧。
- **粗描边 + `inside` 在小图形上会盖满填充。** 调整顺序：先减 `strokeWidth`，或改 `center`/`outside` 让描边向外，而不是继续增大宽度。
- **`stops` 传字符串数组够用就别写对象。** 等分过渡用 `['#a', '#b']` 最简洁；只在需要非均匀 offset 或中间多色时才写 `{ offset, color }`。
- **描边和填充用同一套 paint。** 渐变、图案对象在 `fill` 和 `stroke` 上写法一致，把已知的 paint 对象从 `fill` 搬到 `stroke` 即可描出同款边。
- **图像填充先确认可访问性。** 优先同域资源或 data URL；跨域图片必须服务端配置 CORS，否则填充静默失败。

## 常见问题

- **设了 `strokeWidth` 还是看不到描边？**
  描边由 `stroke` 与 `strokeWidth` **同时**决定。只给 `strokeWidth` 不给 `stroke`（或反过来）都不画——两者缺一不可。
- **矩形的描边把填充盖住了一半？**
  `UI` 基类图形的 `strokeAlign` 默认是 `inside`，描边整条画在填充内侧。想要跨边居中显式写 `strokeAlign: 'center'`，想画到外侧写 `'outside'`。
- **`strokeCap: 'butt'` 写了好像没区别？**
  LeaferJS 用 `'none'` 表示平帽（引擎内部会把它映射为原生 `butt`）。直接写 `'butt'` 也能工作，但官方约定是 `'none'`；想要圆头/方块端点用 `'round'` / `'square'`。
- **闭合多边形上调 `strokeCap` 看不到变化？**
  闭合图形的实线描边没有开放端点，`strokeCap` 不生效。打开 `dashPattern` 后，`strokeCap` 才作用在每个 dash 的两端。
- **渐变方向不对？**
  线性渐变 `from`/`to` 缺省是 `top` → `bottom`（竖直）。要斜向就显式给，如 `from: 'top-left', to: 'bottom-right'`；径向渐变的半径由 `from`→`to` 的距离决定，调整 `to` 即可改变半径。
- **图像填充不显示？**
  先确认 `url` 可访问、无跨域阻挡。跨域图片需服务端返回 CORS 头，否则画不上；本地原型阶段用 data URL 最稳妥。

## 总结回顾

摘要：

LeaferJS 的 `fill` 与 `stroke` 是 `UI` 上并行的两道工序，共用同一套 paint 表达：纯色字符串、`{ type, ... }` 渐变/图案对象，或它们的数组。填充有纯色、线性渐变、径向渐变、图案（image）等画法，描边参数集中在宽度（`strokeWidth`）、对齐（`strokeAlign`）、线帽（`strokeCap`）、拐角（`strokeJoin`）、虚线（`dashPattern`/`dashOffset`）和 `miterLimit` 上。描边由 `stroke` 与 `strokeWidth` 同时决定，二者缺一不画；描边带的位置由 `strokeAlign` 决定，且默认值随元素不同——`UI` 基类图形 `inside`、`Line`/`Path` `center`、`Text` `outside`。`strokeCap` 只作用于开放端点与 dash 两端，闭合实线图形上看不到效果。

一句话：

> `fill` 涂面、`stroke` 描边，两者共用 paint；记住描边「要 `stroke` + `strokeWidth` 同时给」和「`strokeAlign` 默认 inside（`UI` 基类）」就能预测大多数视觉结果。

知识要点：

- `fill` 和 `stroke` 各接受哪几种表达？它们是否共用同一套 paint？
- 想画描边必须同时设置哪两个属性？
- `strokeAlign` 的三档分别把描边带放在哪？默认值在 `Rect`、`Line`、`Text` 上各是什么？
- 线性 / 径向渐变的 `from`/`to` 默认值是什么？`stops` 传字符串数组时 offset 如何计算？
- `strokeCap` 与 `strokeJoin` 分别在什么位置生效？为什么闭合实线图形看不到 `strokeCap`？
- `dashPattern` 的 `number[]` 如何描述节律？`dashOffset` 做什么？
