# 遮罩、裁剪与擦除

mask、clip、eraser 都用来「限定哪些像素最终可见」，但限定发生在不同的层次、作用于不同的对象：

- **mask 遮罩**——把一个**子节点**设为遮罩，它的形状去和同 Group 内已绘制的内容做「保留交集」的合成（`destination-in`）：与遮罩重叠的部分留下，其余丢弃。
- **eraser 擦除**——同样用一个**子节点**，但做相反的「抠掉形状」合成（`destination-out`）：擦除形状覆盖到的区域，相当于打洞。
- **clip 裁剪**——不是独立属性，而是容器（`Box` / `Frame`）的 `overflow: 'hide'`：把超出自身宽高的子内容直接裁掉，是矩形容器裁剪。

记住两条判断轴就能预测大多数结果：**作用对象**——mask / eraser 作用于「同 Group 的兄弟」，clip 作用于「容器的子级」；**合成方向**——mask 保留形状内侧，eraser 移除形状内侧，两者刚好相反。再加上一条形状来源的差异：mask / eraser 可用任意形状（圆、路径、渐变），clip 只按宽高的矩形。下面的实例用一个限定圆在底图上切换这三种手段，对角绿色标记会告诉你 mask（圆）与 clip（方）的边界差在哪。

| 关键输入 | 默认 | 含义与回查要点 |
| --- | --- | --- |
| `mask` | `false` | 设在**子节点**上。`true` 用默认类型 `pixel`，或给具体 `IMaskType`：`path` / `pixel` / `grayscale` / `clipping` / `clipping-path`。影响同 Group 内位于其**上层**的兄弟。 |
| `maskType` | `pixel` | mask 的合成方式（见下文 `### mask`）。`pixel` 按像素透明度、`path` 仅几何（高性能）、`grayscale` 明度蒙版、`clipping` / `clipping-path` 渲染遮罩自身。 |
| `eraser` | `false` | 设在**子节点**上。`true` 用默认类型 `pixel`，或 `'path'` / `'pixel'`。擦除同 Group 内位于其**下层**的兄弟。 |
| `overflow`（clip） | `'show'` | `Box` / `Frame` 上设为 `'hide'`，按容器宽高裁剪**自身子级**（矩形）。`Text` 用 `textOverflow`。 |
| `hitChildren` | `true` | mask / eraser 下子元素默认仍可命中交互；设 `false` 禁用，让 Group 边界严格收拢。 |

## 三种限定手段

三者共享「限定可见区域」这个目标，但实现层次不同，因此选用与排错思路也不同：

- 需要**按任意形状**只露出某区域 → `mask`。
- 需要**按任意形状**打一个洞 → `eraser`。
- 只需要**隐藏容器超出部分**（如卡片切角、滚动裁剪）→ `clip`（`overflow: 'hide'`）。

mask 与 eraser 都建立在「同 Group 兄弟合成」之上：LeaferJS 把该 Group 的内容先画到离屏画布，再用遮罩 / 橡皮擦节点的渲染结果做一次像素合成（`destination-in` 保留交集、`destination-out` 抠掉）。所以它们的关键不在「设在哪」，而在「和谁同组、在上层还是下层」。clip 则完全不同——它是容器自身对子内容的矩形裁剪，不涉及兄弟、不涉及任意形状。下面的实例把底图与限定圆放在同一场景，用「模式」控件在四档间切换，读数同步显示当前的作用对象与限定形状。

### mask 遮罩

把一个子节点的 `mask` 设为 `true` 或具体类型，它就成为同 Group 内的遮罩。遮罩节点**自身不渲染**（`clipping` / `clipping-path` 除外），并影响位于其**上层**的兄弟：兄弟内容只在「与遮罩重叠」处保留，其余被丢弃。底层用 `destination-in` 合成，等价于「保留交集」。

要点是「同组 + 上层」：被遮内容必须放进同一个 `Group`，并 `add` 在遮罩**之后**（z 更高）。放错组或放到底层，遮罩都不会生效。

```ts
import { Leafer, Group, Rect, Ellipse } from 'leafer-ui'

const leafer = new Leafer({ view: window, fill: '#f8fafc' })

const group = new Group()
leafer.add(group)

// 遮罩圆（先加入，位于底层）——影响同 Group 上层兄弟
const mask = new Ellipse({ width: 200, height: 200, fill: '#ffffff' })
mask.mask = true // 等价于 mask: 'pixel'（默认类型）
group.add(mask)

// 底图（后加入，位于上层）——只露出遮罩圆部分
group.add(new Rect({ x: 40, y: 40, width: 320, height: 200, fill: '#4f7cff' }))
```

遮罩圆的 `fill` 对 `pixel` 类型有意义（按像素透明度合成）：半透明填充会产生半透明遮罩、渐变填充会产生软边。`mask` 默认把遮罩边界作为 Group 的边界，但子元素默认仍可触发交互（除非 `hitChildren: false`）。

### clip 裁剪

clip 不是独立属性，而是 `Box` / `Frame` 的 `overflow: 'hide'`：它把**超出容器宽高**的子内容直接裁掉，作用对象是「容器的子级」，不是兄弟，限定形状恒为矩形。

```ts
import { Leafer, Box, Ellipse } from 'leafer-ui'

const leafer = new Leafer({ view: window, fill: '#f8fafc' })

// Box 用 overflow:'hide' 把超出自身宽高的子内容裁掉（矩形裁剪）
const box = new Box({ width: 200, height: 200, overflow: 'hide' })
leafer.add(box)

// 子椭圆超出 Box，超出部分被裁剪
box.add(new Ellipse({ x: 120, y: 120, width: 160, height: 160, fill: '#FEB027' }))
```

选实例的 `mode = clip`：底图被裁成矩形，对角绿色标记在 clip 内可见——它们位于矩形角（约 1.41r）但圆外（r），所以在 mask 下不可见、在 clip 下可见，正好区分两种限定形状。clip 容器**仍会渲染自身**（可以同时有 `fill` / `stroke`），裁剪只是叠加其上的行为。文本裁剪用 `Text` 的 `textOverflow: 'hide'`（或自定义省略串）。

### eraser 擦除

把子节点的 `eraser` 设为 `true` 或类型，它就成为橡皮擦，擦除同 Group 内位于其**下层**的兄弟。底层用 `destination-out` 合成，把擦除形状覆盖的区域抠掉，相当于在内容上打洞——方向与 mask 正好相反。

```ts
import { Leafer, Group, Rect, Ellipse } from 'leafer-ui'

const leafer = new Leafer({ view: window, fill: '#f8fafc' })

const group = new Group()
leafer.add(group)

// 底图（先加入，位于底层）
group.add(new Rect({ x: 40, y: 40, width: 320, height: 200, fill: '#4f7cff' }))

// 橡皮擦圆（后加入，位于顶层）——擦除同 Group 下层兄弟
const eraser = new Ellipse({ x: 140, y: 40, width: 160, height: 160, fill: '#000000' })
eraser.eraser = true // 等价于 eraser: 'pixel'（默认类型）
group.add(eraser)
```

`eraser` 同样**自身不渲染**，`fill` 的透明度只对 `pixel` 类型有意义（半透明擦除 = 部分擦除）；`path` 类型按几何硬擦。选实例的 `mode = eraser`：底图中心被挖出圆形洞，中心白点与内侧黄点被擦除，外圈绿/橙点保留——因为它们在限定圆之外。

## 最佳实践

- **按形状限定用 mask / eraser，矩形溢出隐藏用 clip。** clip 只做矩形容器裁剪；想用圆、路径、渐变去限定可见区域，只能用 mask（保留）或 eraser（抠掉）。
- **纯硬边遮罩 / 擦除切 `path` 提性能。** `pixel` 要逐像素合成，较重；`path` 只用几何裁剪，更快，但忽略透明度。
- **需要软边或半透明效果只能选 `pixel`。** `path` 按几何裁剪，不读取填充透明度，做不出渐变软边或半透明遮罩。
- **想保留遮罩形状自身可见，用 `clipping` / `clipping-path`。** 其余类型遮罩节点自身不渲染；`clipping` 类似 PS 剪贴蒙版，遮罩圆会被画出来，下面的内容同时被它限定。
- **mask / eraser 的成败关键在「同组 + 上下层」。** 内容与限定节点必须在同一 `Group`；mask 放底层（内容在上），eraser 放顶层（内容在下）。

## 常见问题

- **设了 `mask` 却看不到效果？**
  被遮内容必须在**同一 Group** 且位于遮罩**上层**（`add` 在遮罩之后）。mask 只影响同组上层兄弟；内容在别的组、或加在遮罩之下都不会被遮。
- **`eraser` 擦不掉？**
  eraser 擦除同组**下层**兄弟。把 eraser 节点 `add` 到被擦内容**之后**（位于顶层）；放到底层就擦不到上面的内容。
- **想按任意形状裁剪，`overflow` 不生效？**
  `overflow: 'hide'`（clip）只按容器宽高的**矩形**裁剪，且作用对象是容器的子级。要用圆、路径等形状限定可见区域，改用 `mask`。
- **mask 节点本身看不到了？**
  这是设计行为：除 `clipping` / `clipping-path` 外，遮罩节点**自身不渲染**，只贡献形状 / 像素给合成。想让遮罩形状同时可见，用 `clipping` 或 `clipping-path`。
- **遮罩做不出软边 / 半透明？**
  `maskType` 可能是 `path`——它按几何裁剪，忽略填充透明度。软边或半透明遮罩要用默认的 `pixel`（按像素透明度合成）。

## 总结回顾

摘要：

mask、clip、eraser 都限定可见区域，但层次不同。mask / eraser 建立在「同 Group 兄弟合成」上：mask 把一个子节点设为遮罩，用 `destination-in` 保留它与同组上层兄弟的交集；eraser 把一个子节点设为橡皮擦，用 `destination-out` 抠掉它覆盖到的同组下层兄弟。两者都支持任意形状（圆 / 路径 / 渐变），遮罩节点自身不渲染（`clipping` / `clipping-path` 除外）。mask 的默认类型 `pixel` 按像素透明度合成，`path` 改用几何裁剪以提性能（但忽略透明度），`grayscale` 把明度转为透明度。clip 不是独立属性，而是 `Box` / `Frame` 的 `overflow: 'hide'`，按容器宽高的矩形裁剪自身的子级。判断时记住三条轴：作用对象（兄弟 vs 子级）、合成方向（保留 vs 抠掉）、形状来源（任意 vs 矩形）。

一句话：

> mask 用兄弟形状保留内侧、eraser 用兄弟形状抠掉内侧、clip 用容器矩形裁剪子级——选哪个看「限定什么形状」和「作用于谁」。

知识要点：

- mask / eraser / clip 分别作用于谁？前两者为什么必须在同一个 Group？
- mask 与 eraser 的合成方向有什么不同？它们分别影响上层还是下层兄弟？
- 想按任意形状裁剪该用哪个？`overflow: 'hide'` 能做到吗？
- `maskType` 的默认值是哪个？`path` 与 `pixel` 在透明度处理上有什么区别？
- 哪些 `maskType` 会把遮罩节点自身也渲染出来？
- 把限定圆从「保留内侧」改成「抠掉内侧」，需要切换哪个属性 / 模式？
