# 文本

`Text` 是 leafer-ui 的文字节点，把一段字符串按字体样式渲染到画布，并自动完成排版与测量。它回答三件事：文字长什么样（字体、字号、字重、颜色）、文字如何在文本框内排布（自动换行、对齐、行高），以及文字占多大空间（文本框包围盒与逐行测量数据）。

一个 `Text` 节点 = 一个字符串 + 一套字体样式 + 一个可选的文本框宽度。**未设宽度时它贴合内容排成单行；设了宽度就按宽度自动换行。** 据此可以预测下方实例的结果：改字体或行高 → 文字外观和文本框尺寸变化；改宽度 → 行数变化；改对齐 → 只在宽度固定时才有可见效果。

下面这张表是回查入口，默认值核对自 leafer-ui 2.2.9 的 `Text` 源码（`@boundsType` 装饰器）。

| 属性 | 默认值 | 说明 / 回查要点 |
| --- | --- | --- |
| `text` | `''` | 文字内容；支持 `\n` 手动断行 |
| `fill` | `'#000000'` | 文字填充色（继承自 UI） |
| `fontFamily` | `'caption'` | 主题字体 token，可设 CSS 字体族字符串 |
| `fontSize` | `12` | 字号，单位 px |
| `fontWeight` | `'normal'`（=400） | 字重：`100`–`900` 或 `thin`…`black` |
| `italic` | `false` | 是否斜体 |
| `lineHeight` | `1.5 × 字号` | `{ type:'percent', value:1.5 }`；**裸数字按 px 解释** |
| `letterSpacing` | `0` | 字间距，单位 px |
| `textAlign` | `'left'` | 水平对齐：`left` / `center` / `right` / `justify` |
| `verticalAlign` | `'top'` | 垂直对齐：`top` / `middle` / `bottom` |
| `textWrap` | `'normal'` | `normal` 按词换行 / `break` 断字 / `none` 不换行 |
| `textOverflow` | `'show'` | `show` / `hide` / `ellipsis` / 自定义省略串 |
| `width` / `height` | `0`（自动） | `0` = 自动宽高；`>0` = 固定并按此换行 / 裁剪 |
| `autoSizeAlign` | `true` | 自动尺寸时是否按对齐方向偏移 |
| `padding` | 未设 | 文本框内边距，支持 `[上, 右, 下, 左]` |

## 字体样式

字体相关属性都直接挂在 `Text` 节点上，整段文字共用一套样式。`fontFamily` 给字体族、`fontSize` 给字号、`fontWeight` 给字重、`fill` 给颜色，这四项决定了文字的基本外观。

```ts
import { Leafer, Text } from 'leafer-ui'

const text = new Text({
  text: 'Hello LeaferJS',
  fontSize: 24,
  fontWeight: 'bold', // 'bold' 会被映射为 700
  fill: '#32cd79',
})
```

样式调节的可观察证据见下方「换行与对齐」实例——本课所有控件共用同一个 Canvas，调「字号」「行高」「字间距」「填充色」即可在画布与左下角读数中核对效果。

需要留意的边界：

- `fontFamily` 默认是 `'caption'` 这个主题字体 token；设自定义字体时，字体需已被浏览器加载完成，否则按回退字体测量。
- `fontWeight` 的字符串值（`normal`、`bold` 等）会被映射为数字（400、700），最终拼进 Canvas 的 `font` 字符串。
- `textCase`（`upper` / `lower` / `title` / `small-caps`）、`textDecoration`（`under` / `delete`）、`italic` 只改变字形或加装饰线，不影响测量单位。

## 换行与对齐

换行由 **文本框宽度 `width`** 与 **换行策略 `textWrap`** 共同决定，这是 Text 最容易踩坑的地方：

- **`width` 为 0（默认，自动宽度）**：文本框贴合内容，文字排成单行，不换行（`\n` 仍可手动断行）。
- **`width` 设为正数（固定宽度）**：文字按此宽度自动换行，行数随宽度和字号变化。
- **`textWrap`**：`normal`（默认）在不拆开单词的前提下换行；`break` 允许在词内断行（类似 CSS `break-all`）；`none` 即使宽度固定也不换行。

对齐在「固定宽度的文本框」内才有意义：`textAlign` 控制水平方向、`verticalAlign` 控制垂直方向。**自动宽度时文本框贴合内容，对齐没有可见空间，切换 `textAlign` 不会有视觉变化。** `padding` 给文本框内边距，`textOverflow` 控制内容超出固定框时是 `show` / `hide` / `ellipsis`。

```ts
const text = new Text({
  text: '一段较长的文字内容，会按下面的宽度自动换行……',
  width: 200,            // 固定宽度 → 触发自动换行
  fontSize: 16,
  textAlign: 'center',   // 在 200px 宽的文本框内居中
  lineHeight: { type: 'percent', value: 1.6 }, // 1.6 倍行高
})
```

## 文字测量

渲染完成后，Text 提供三组测量入口（访问这些 getter 会自动触发布局更新，读取顺序无要求）：

- **`text.boxBounds`**：文本框包围盒 `{ x, y, width, height }`，本地坐标，单位 px。自动宽度时等于内容大小；固定宽度时等于设定的框。
- **`text.textDrawData`**：文字绘制数据，其中 `bounds` 是文字内容包围盒、`rows` 是逐行数组（每行含 `width` / `height` / `text`）、`font` 是当前 Canvas 字体串。
- **`text.isOverflow`**：布尔值，内容是否溢出固定文本框。

```ts
text.boxBounds                 // 文本框 { width, height, ... }
text.textDrawData.rows.length  // 实际渲染行数
text.textDrawData.bounds.width // 内容宽度（最宽一行）
text.isOverflow                // 是否溢出固定框
```

上方实例左下角的四项读数即分别取自这四个入口：「文本框」= `boxBounds` 的宽 × 高、「行数」= `rows.length`、「内容宽」= `textDrawData.bounds.width`、「溢出」= `isOverflow`。把宽度调小会看到行数上升、文本框高度上升；把高度维度的影响留给 `lineHeight`——它只改变每行高度，不改变行数。

## 富文本与多样式

`Text` 节点本身是「一段文字、一套样式」——整段共用同一组字体属性。同一段落内要混合多种样式（如不同颜色、字号、加粗）时，有两条路径：

- **多个 `Text` 节点组合**：canvas 原生做法，最稳定可控。把每段不同样式的文字做成独立 `Text`，按 `x` / `y` 或自动布局排列，适合样式段较少的场景。
- **`HTMLText` 插件（`@leafer-in/html`）**：在 `text` 中内嵌 HTML 标签（如 `<span style="color:red">红字</span>`），由插件解析后按 SVG 渲染，适合复杂内联样式。它**不属于 `leafer-ui` 基础包**，需单独安装引入，渲染路径与原生 Canvas 文字不同。

文字的双击内联编辑（在画布上直接修改文字内容）由 `@leafer-in/text-editor` 提供，见「文字编辑器」课。

## 常见问题

- 设了 `textAlign: 'center'` 但文字没居中。
  先确认是否给了固定 `width`。自动宽度（`width = 0`）时文本框贴合内容，对齐没有生效空间；把 `width` 设为正数，文字才会在框内居中。
- 设了 `width` 但文字仍不换行。
  检查 `textWrap` 是否被设成了 `'none'`（默认 `'normal'` 才换行）。需要在中文字符或长单词中间断行时用 `'break'`。
- `lineHeight: 1.5` 后行高变得极小。
  裸数字按 **px** 解释，`1.5` 会被当成 `1.5px`，不是 1.5 倍。要按倍数需写 `{ type: 'percent', value: 1.5 }`，默认值即此形式。
- 设了 `textOverflow: 'ellipsis'` 却看不到省略号。
  溢出裁剪需要 `height` 固定；自动高度会随内容增长而不触发裁剪。给 `Text` 一个固定 `height` 再观察省略号。

## 总结回顾

摘要：

`Text` 用一个字符串加一套字体样式渲染文字，并通过可选的 `width` 决定排版：未设宽度时贴合内容排成单行，设了宽度就按 `textWrap` 策略自动换行。对齐只在固定宽度的文本框内才有意义。渲染后的尺寸与行数可经 `boxBounds`、`textDrawData`（含 `rows`）和 `isOverflow` 精确读出。整段多样式不是基础 `Text` 的能力，要用多个节点组合或 `HTMLText` 插件。

一句话：

> `width` 决定换行、固定宽度下对齐才生效、测量读 `boxBounds` 与 `textDrawData`。

知识要点：

- 哪个属性决定 Text 是否自动换行？
- `textAlign` 在什么前提下才有可见效果？
- 裸数字 `lineHeight` 与 `{ type:'percent' }` 的 `lineHeight` 有何区别？
- 怎样读出文本框尺寸与实际行数？
- 一段内要混合多种样式时有哪些方案？
