# 箭头元素

`@leafer-in/arrow` 提供的 **Arrow** 是一条带端点箭头的线 / 路径。它继承自 `Line`，所以 `points`、`curve`、`cornerRadius`、`stroke` 等全部沿用 Line 的能力；多出来的只是两个端点箭头属性 `startArrow` / `endArrow`。最关键的一点：**箭头方向由引擎按端点所在线段的切线自动计算**——折线上首尾两段方向不同时，两端箭头会各自跟随对应线段指向不同方向，无需手设旋转。调节下面的「终点箭头」「描边宽度」「箭头比例」即可预测：箭头形状随类型变、尺寸随描边宽等比变、`scale` 只放大箭头不变线条。

| 输入 / 属性 | 默认 / 取值 | 回查要点 |
| --- | --- | --- |
| `Arrow`（继承 `Line`） | `import { Arrow } from '@leafer-in/arrow'` | 画一条带箭头的线 / 路径；`points`、`curve`、`cornerRadius`、`stroke` 等均继承自 Line |
| `endArrow` | `'angle'` | 终点箭头；字符串=内置样式名，对象 `{ type, scale?, rotation? }` 可缩放 / 旋转 |
| `startArrow` | `'none'` | 起点箭头；取值与 `endArrow` 一致，默认无 |
| 内置箭头类型 | 13 种 | `angle` `angle-side` `arrow` `triangle` `triangle-flip` `circle` `circle-line` `square` `square-line` `diamond` `diamond-line` `mark`（加 `none`） |
| 箭头尺寸 | 随 `strokeWidth` | 箭头按"线宽 1"设计，引擎按 `strokeWidth` 自动缩放；`{ type, scale }` 在此基础上再放大 |
| `Arrow.registerArrow(name, data)` | — | 注册自定义箭头；`data.path` 仅支持 `M L C Q O`，尖点落在 `(0,0)`、按线宽 1 设计 |

## 箭头元素与端点跟随

Arrow 继承 Line，本质是一条线 + 两个端点箭头。只给 `stroke` 与 `strokeWidth`、不设任何箭头属性时，终点已经会自动出现箭头——因为 `endArrow` 默认就是 `'angle'`；`startArrow` 默认 `'none'`，所以起点默认没有箭头。

```ts
import { Leafer } from 'leafer-ui';
import { Arrow } from '@leafer-in/arrow';

const leafer = new Leafer({ view: canvas, fill: '#fff' });

// 仅描边即可：endArrow 默认 'angle'，引擎自动在终点生成 V 形箭头
const arrow = new Arrow({
  points: [50, 50, 250, 50],
  stroke: '#32cd79',
  strokeWidth: 4,
});

leafer.add(arrow);
```

箭头方向不需要手设：引擎取端点所在线段（首段 / 末段）的切线作为箭头朝向。当下方实例的折线带一个 L 形拐角时，**首段水平 → 起点箭头朝左；末段竖直 → 终点箭头朝上**，两端自然指向不同方向，这就是"端点跟随"。三个浅灰小圆点标出折线的顶点，帮助辨认路径结构。

| 读者操作 | 可观察证据 |
| --- | --- |
| 切换「终点箭头」 | 终点箭头形状随类型变化（`angle`=开口 V、`arrow`=实心、`circle`=圆 …） |
| 切换「起点箭头」为非 `none` | 起点出现箭头；因折线有拐角，起点箭头朝左、终点箭头朝上 |
| 调「描边宽度」 | 线条变粗，箭头同步等比放大（箭头尺寸 = strokeWidth × 设计比例） |
| 调「箭头比例」 | 仅箭头在描边宽度之上再放大，线条粗细不变（对象形式 `{ type, scale }`） |

**边界：** Arrow 本身是 Line，必须有可画的路径几何——给 `points`（折线坐标 `[x,y, …]`）、`toPoint`（两点直线），或继承自 Line 的路径。箭头方向只能由引擎按切线自动决定，没有"直接设箭头角度"的属性；要在自动朝向基础上微调，用 `{ type, rotation }` 做增量旋转。闭合路径（`Path` 的 `Z` 命令）没有开放端点，不会生成箭头。引入 `@leafer-in/arrow` 插件后，`startArrow` / `endArrow` 会挂到所有 UI 元素上，因此 `Line` 与 `Path` 也能直接带箭头，并非 Arrow 独占。

## 箭头样式

`startArrow` / `endArrow` 的取值类型 `IArrowStyle` 有三种形式：**字符串**（内置样式名）、**对象 `{ type, scale, rotation }`**（在内置样式上缩放 / 旋转）、**自定义路径对象**（`registerArrow` 注册后按名引用，或直接传入 `IPathDataArrow`）。本课实例的「箭头比例」控件用的就是第二种——把 `endArrow` 传成 `{ type, scale }`，让 `scale` 单独放大箭头。

### 内置箭头与缩放旋转

13 种内置箭头按形态可分为实心（闭合填充）与描边型（`-line` 后缀，镂空轮廓）两类，外加 `angle` / `angle-side` / `mark` 三种特殊形态：

| 类型 | 形态 | 类型 | 形态 |
| --- | --- | --- | --- |
| `none` | 无箭头 | `circle` | 实心圆 |
| `angle` | 开口 V 形（默认，性能佳） | `circle-line` | 圆环（描边圆） |
| `angle-side` | 单边 V 形（仅一侧带线） | `square` | 实心方块 |
| `arrow` | 标准实心箭头 | `square-line` | 方框（描边方块） |
| `triangle` | 实心三角形 | `diamond` | 实心菱形 |
| `triangle-flip` | 反向三角形 | `diamond-line` | 菱形框（描边） |
| `mark` | 短刻度（过端点的垂线，如标注） | | |

要在一个内置样式上额外缩放或旋转，把字符串换成对象 `{ type, scale, rotation }`：

```ts
const arrow = new Arrow({
  points: [50, 50, 250, 50],
  stroke: '#32cd79',
  strokeWidth: 5,
  endArrow: {
    type: 'triangle', // 引用内置样式名
    scale: 2,         // 在 strokeWidth 基准上再放大 2 倍
    rotation: 30,     // 相对线段自动朝向再增量旋转 30°
  },
});
```

**边界：** `scale` 过大时实心箭头可能超出原始设计比例；v2.2.9 起，放大的箭头会优先使用专门的填充路径数据，缓解变形。`rotation` 是在自动朝向基础上的增量角度，正值顺时针，不会改变箭头跟随切线这一基准行为。

### 自定义箭头

`Arrow.registerArrow(name, data)` 把一个自定义箭头注册进全局列表，之后用字符串名引用，与内置样式用法完全一致。`data` 是 `IPathDataArrow`：

```ts
// path 为命令数组：1=moveTo(M)、2=lineTo(L)、3=bezierCurveTo(C)、4=quadraticCurveTo(Q)、7=arc(O)
// 下例等价于 moveTo(-5,-5).lineTo(0,0).lineTo(-5,3) 的 V 形箭头
Arrow.registerArrow('custom-arrow', {
  connect: { x: -0.5 }, // 箭头与线端的连接点偏移（按线宽 1 的比例）
  offset: {
    // 相对线端的额外偏移；bevelJoin / roundJoin 在 strokeJoin 为对应值时额外补偿
    x: -0.71,
    bevelJoin: 0.36,
    roundJoin: 0.22,
  },
  path: [1, -5, -5, 2, 0, 0, 2, -5, 3], // 仅支持 M L C Q O 命令
  // fill: true, // v2.2.9+ 启用填充
});

const arrow = new Arrow({
  points: [50, 50, 250, 50],
  stroke: '#32cd79',
  strokeWidth: 5,
  endArrow: 'custom-arrow', // 注册后按名引用
});
```

设计约定：**箭头按从左到右绘制、尖点落在 `(0,0)`、坐标按"线宽为 1"设计**；引擎会自动套用 `strokeWidth` 缩放与线段切线旋转，你只需给出单位比例下的形状。`path` 命令数组只支持 `M L C Q O`（`moveTo` / `lineTo` / `bezierCurveTo` / `quadraticCurveTo` / `arc`），不支持闭合 `Z`。`registerArrow` 写入全局 `PathArrow` 列表，同名会覆盖；注册后所有 `Arrow` / `Line` / `Path` 都能按名引用。

## 最佳实践

- **只调箭头大小、不想加粗线条，用 `{ type, scale }`。** 箭头尺寸本就随 `strokeWidth` 等比缩放；要让箭头更大却保持线条不变，用对象形式的 `scale`，而不是加大 `strokeWidth`（那会让整条线一起变粗）。
- **双向箭头显式开 `startArrow`。** Arrow 默认只有终点箭头（`endArrow: 'angle'`），起点默认 `none`。尺寸标注、力的方向、可逆流程等双向场景显式设 `startArrow`；单向流程箭头保持默认即可。
- **箭头方向交给引擎，不要手算旋转。** 端点箭头自动跟随所在线段的切线，移动 `points` 或旋转元素时箭头会自动跟着转。只在需要相对切线偏转一个固定角度（如垂直于线段的标注头）时才用 `{ type, rotation }`。

## 常见问题

- **箭头太大 / 太小，但调 `strokeWidth` 线条也跟着变粗 / 变细。**
  箭头尺寸随 `strokeWidth` 等比缩放。只想改箭头，把 `endArrow` 改成对象形式 `{ type: 'arrow', scale: 2 }`，`scale` 在 `strokeWidth` 基准上单独放大或缩小箭头，不影响线条粗细。
- **路径用了 `Z` 闭合，端点没有箭头。**
  闭合路径（`Z` 命令）没有开放端点，引擎跳过箭头绘制。需要箭头就去掉 `Z` 保持路径开放，或把箭头单独画在一条开放路径上。
- **给箭头加了 `dashPattern`（虚线），箭头变成了实线。**
  这是预期行为：虚线模式下箭头仍按实线绘制（引擎为箭头临时关闭虚线），以保证箭头形状完整。最终效果是整条线虚线、端点箭头实心。
- **想让 `Line` 或 `Path` 也带箭头。**
  引入 `@leafer-in/arrow` 插件后，`startArrow` / `endArrow` 属性就挂到了所有 UI 元素上，可直接在 `Line`、`Path` 上使用，不必非得用 `Arrow` 类。`Arrow` 只是预设了 `endArrow` 默认值 `'angle'` 的便捷子类（`Line` / `Path` 的端点箭头默认都是 `'none'`）。

## 总结回顾

摘要：

Arrow 是 `@leafer-in/arrow` 提供的线 + 端点箭头元素，继承 `Line`，沿用 `points` / `curve` / `cornerRadius` / `stroke` 等全部能力。`endArrow` 默认 `'angle'`（自动有箭头），`startArrow` 默认 `'none'`；箭头方向由引擎按端点所在线段的切线自动计算，折线上两端箭头各自跟随首末段、可指向不同方向。箭头样式通过 `IArrowStyle` 三种形式给出：字符串（13 种内置样式）、对象 `{ type, scale, rotation }`（在内置样式上缩放 / 旋转）、自定义路径（`Arrow.registerArrow` 注册后按名引用，按"线宽 1、尖点 `(0,0)`"设计，仅支持 `M L C Q O`）。箭头尺寸随 `strokeWidth` 缩放，单独放大用 `scale`。引入插件后 `Line` 与 `Path` 也能用 `startArrow` / `endArrow`。

一句话：

> Arrow 是一条端点箭头自动跟随线段切线的线，箭头样式从 13 种内置样式、对象缩放 / 旋转或自定义路径中任选其一。
