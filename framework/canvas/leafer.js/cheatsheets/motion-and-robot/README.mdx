# 运动路径与精灵帧

`@leafer-in/motion-path` 和 `@leafer-in/robot` 是两个为「运动」服务的独立插件，合起来正好覆盖游戏角色最常见的需求：**沿路径走** + **按帧动**。它们的对象模型都很轻：

- **运动路径** 把一条 `Path` 变成「路径提供者」，同级元素靠 `motion` 属性贴着这条路径走。一句话建立直觉：**`motionPath: true` 标记的是路径，`motion` 控制的是跟随者在路径上的位置**。
- **Robot** 是一个类似游戏精灵的 UI 元素，喂它一张（或多张）雪碧图，它自动按帧编号剪辑播放；`actions` 把帧组合成命名动作，`action` 一切换就换一套动作。一句话：**`robot` 定义帧图，`actions` 定义动作，`action` / `play` 决定现在播哪段**。

二者各管一摊，但可以叠加——让 Robot 当跟随者，就是「精灵沿路径行走」。它们和动画系统的分工是：`@leafer-in/animate` 的 `animate()` 负责任意属性的关键帧插值（见「动画系统」一课）；运动路径负责「贴着曲线走」并把 `motion` 注册成可动画属性；Robot 负责「按帧图播放」。三者常组合使用。

**前置：** 两个插件都必须显式引入，`leafer-ui` 本体里这些方法只是空桩。

```ts
import '@leafer-in/motion-path';        // 注册 motion/motionPath 等属性并改写路径方法
import { Robot } from '@leafer-in/robot'; // 命名导入会触发 @registerUI 注册 Robot 元素
```

也可以直接装 `leafer-game`，它已集成 Robot、运动路径、动画、交互状态等插件，`import { ... } from 'leafer-game'` 即可。

## 关键输入与默认值

下表的默认值来自 `@leafer-in/motion-path` 2.2.9 源码（`UI.addAttr`）与 `@leafer-in/robot` 的属性注册。

| 属性 | 默认值 | 含义与回查要点 |
| --- | --- | --- |
| `motionPath` | `undefined` | 设为 `true` 才把该元素标记为路径提供者。不设则 `motion` 无路径可循。 |
| `motion` | `undefined` | 跟随者在路径上的位置。**数字 = 绝对距离（px）**；`{ type:'percent', value }` = 按总长比例。默认空表示不参与运动。 |
| `motionRotation` | `true` | `true` 自动转向路径切线；`false` 保持竖直；数字 = 在切线方向上再偏移这么多度。 |
| `motionAround` | `undefined`（= 左上角） | 跟随者哪个点贴在路径上。设 `'center'` 让中心贴路径。 |
| `motionPrecision` | `1` | 路径取点精度，越小越细但越耗。 |
| `motionVertical` | `'below'` | 文本相对路径的上 / 下放置（`motionText` 用）。 |
| Robot `robot` | `undefined` | 帧图定义：`{ url, size, total, offset?, mode? }` 或其数组。 |
| Robot `FPS` | `12` | 动作帧率，`__runAction` 每帧重读，改了立即生效。 |
| Robot `loop` | `true` | 动作是否循环。 |
| Robot `now` | `0` | 当前帧编号（0 起），可读可写。 |
| Robot `action` | `''` | 当前动作名，切换会重建动作定时器。 |

## 运动路径：沿 Path 运动

运动路径的对象关系是「提供者 + 跟随者」一对：把一个元素设为 `motionPath: true`，**同一父级下的兄弟元素**只要 `motion` 不为空，就会贴着这条路径走。最小写法：

```ts
import '@leafer-in/motion-path';
import { Group, Leafer, Path, Rect } from 'leafer-ui';

const leafer = new Leafer({ view: canvas, fill: '#f8fafc' });
const group = new Group();

const path = new Path({
  path: 'M 40 120 C 160 20, 320 220, 440 120',
  motionPath: true,           // 标记为路径提供者
  stroke: '#cbd5e1', strokeWidth: 2, dashPattern: [6, 6],
});

const follower = new Rect({
  width: 24, height: 24, fill: '#6366f1',
  around: 'center',           // 中心贴路径（等同 motionAround:'center'）
  motion: { type: 'percent', value: 0.5 }, // 走到路径 50% 处
});

group.add(path);
group.add(follower);           // 必须是 path 的兄弟，不是子元素
leafer.add(group);
```

### motion：位置与进度

`motion` 描述跟随者在路径上的位置，两种写法语义不同，是最高频的混淆点：

- **数字** —— 绝对距离（像素）。`motion: 120` 表示沿路径走 120px。
- **百分比对象** —— 按路径总长比例。`motion: { type: 'percent', value: 0.5 }` 表示走到正中间，与路径实际长度无关。

想拿总长度或任意位置坐标，用两个方法（路径元素和跟随者都能调，跟随者会自动找到同级的路径提供者）：

```ts
const total = follower.getMotionTotal();        // 路径总长（px）
const point = follower.getMotionPoint(          // 路径上某点的 { x, y, rotation }
  { type: 'percent', value: 0.5 },
  'center',                                     // 可选：按哪个锚点取点
);
```

上方实例的读数「运动进度」「朝向」就是用 `getMotionPoint` 在当前百分比处取出的切线角度换算的。

### 朝向与锚点：motionRotation / motionAround

跟随者默认会**自动转向路径切线**（`motionRotation: true`），所以沿曲线走时朝向自然变化。三种取值：

- `motionRotation: true`（默认）—— 朝向 = 路径切线方向。
- `motionRotation: false` —— 不转向，保持竖直（上方实例关掉「朝向跟随路径」即是）。
- `motionRotation: 45` —— 在切线方向上再加 45° 偏移，用于微调角色朝向。

`motionAround` 决定跟随者的哪个点对齐路径：默认是左上角（`undefined`），设 `'center'` 让中心贴路径，角色就不会「偏在一侧」。上方实例的 Robot 就设了 `motionAround: 'center'`。

### 路径生长：提供者自身也参与运动

路径提供者自己也能设 `motion`——此时它不再搬运跟随者，而是**只渲染到该进度为止的子路径**，呈现「描边生长」效果（常用于进度条、绘制动画）：

```ts
const path = new Path({
  path: 'M 40 120 C 160 20, 320 220, 440 120',
  motionPath: true,
  stroke: '#32cd79', strokeWidth: 20,
  motion: { type: 'percent', value: 0.3 },  // 只描出前 30% 的路径
});
```

让 `motion` 动起来就是自动行走 / 自动生长。`@leafer-in/motion-path` 已把 `motion` 注册为可过渡属性，配合 `@leafer-in/animate` 即可：

```ts
import '@leafer-in/animate';
// 沿路径运动至 100%，9 秒一个来回无限循环
follower.animate({ motion: { type: 'percent', value: 1 } }, { duration: 9, loop: true });
// 路径自身描边生长至 100%
path.animate({ motion: { type: 'percent', value: 1 } }, { duration: 9, loop: true });
```

## Robot：精灵帧动画

Robot 是一个 UI 元素，喂它一张雪碧图，它按帧编号剪辑播放。最小写法：

```ts
import { Robot } from '@leafer-in/robot';

const robot = new Robot({
  robot: { url: '/image/arrows.png', size: { width: 100, height: 100 }, total: 20 },
  actions: {
    up: 0,                       // 数字：静止停在第 0 帧
    arrowUp: [0, 1, 2, 3, 4],    // 数组：循环播放这些帧
  },
  action: 'arrowUp',             // 当前动作
});
leafer.add(robot);
```

### robot：帧图与雪碧图

`robot` 接收一个 `IRobotKeyframe` 或其数组，最常见的是单张雪碧图：

| 字段 | 作用 |
| --- | --- |
| `url` | 雪碧图地址。 |
| `size` | 单帧尺寸，`{ width, height }` 或单个数字。 |
| `total` | 总帧数。给出后帧自动从 `0` 编号到 `total - 1`。 |
| `offset?` | 首帧在图上的起点 `{ x, y }`，默认 `{0,0}`。 |
| `mode?` | `'normal'` / `'clip'`，剪辑方式。 |

Robot 按「从左到右、铺满一行后换到下一行」的顺序剪辑每一帧（换行条件是 `x + width >= image.width`）。所以规划雪碧图时，要么单行排满，要么按图宽整除帧宽来分行。上方实例的 `makeWalkSprite` 就是单行排了 8 帧、帧宽 80、图宽 640。

需要每个动作用不同尺寸的图时，传数组：`robot: [{ url, size, total }, { url, size, total }]`，帧编号会跨图连续累加。

### actions / action：预设动作

`actions` 是一个「名字 → 帧组合」的映射，把裸帧编号组织成语义动作；`action` 指定当前播放哪个。三种帧组合：

```ts
actions: {
  idle: 3,                                 // 数字：静止帧
  walk: [0, 1, 2, 3, 4, 5, 6, 7],          // 数组：循环播放
  attack: { keyframes: [8, 9, 10], loop: false, FPS: 20 }, // 对象：带本动作专属参数
}
```

切换 `robot.action = 'walk'` 会自动停止旧动作、按新动作重排定时器。上方实例「精灵动作」在 `walk`（循环帧）与 `idle`（静止帧）间切换，正是这条机制。

### 播放控制：play / pause / FPS / now

Robot 实现了 `IPlayerMethods`，并提供实时帧状态：

| 方法 / 属性 | 作用 |
| --- | --- |
| `play()` / `pause()` / `stop()` / `togglePlay()` | 运行 / 暂停 / 停止 / 切换。`pause` 后帧冻结。 |
| `now` | 当前帧编号（0 起），可直接赋值跳帧。 |
| `FPS` | 帧率，默认 `12`，改了立即生效（无需重建动作）。 |
| `loop` | 是否循环，默认 `true`。 |
| `running` | 只读，是否正在播放。 |
| `nowFrame` / `robotFrames` | 只读，当前帧 / 全部帧的计算结果。 |

循环播放的动作靠内部递归 `setTimeout`（周期 `1000 / FPS`）驱动，**它不随元素销毁自动停止**：销毁 Robot 前应先 `pause()` 并清掉其内部定时器（上方实例 `dispose()` 里就这么做）。

## 最佳实践

- **跟随者还是生长路径？** 要把元素搬过去用「同级跟随者 + `motion`」；要表达「绘制 / 进度」用「路径提供者自身设 `motion`」做生长。同一个 `motionPath: true` 元素，设了自身 `motion` 就转为生长、不再搬运兄弟。
- **`motion` 用百分比还是数字？** 需要与路径长度无关的「从头到尾」语义就用 `{ type:'percent', value }`；需要精确像素位置（如贴在某个刻度）用数字。动画 `motion` 时也优先百分比，避免路径改长后动画失真。
- **Robot 雪碧图布局** 单行排满最省心；多行时确保 `图片宽 / 帧宽` 为整数，否则换行错位。帧编号从 0 起、跨图连续，`actions` 里引用的就是这些编号。
- **何时用 leafer-game** 只要同时需要 Robot、运动路径、动画、交互状态中的两个以上，直接装 `leafer-game` 比逐个引入 `@leafer-in/*` 更省事，且版本统一。

## 常见问题

- **设了 `motion` 但元素不动 / `getMotionPoint` 返回空**
  忘了 `import '@leafer-in/motion-path'`，`leafer-ui` 本体的路径方法是空桩。先确认副作用导入在入口执行；另外跟随者必须是 `motionPath: true` 元素的**同级兄弟**，父子嵌套找不到路径。
- **`motion: 0.5` 不是走到一半**
  数字是绝对距离（0.5px），不是比例。要走一半用 `{ type:'percent', value: 0.5 }`。
- **跟随者偏在路径一侧 / 中心没对齐**
  默认 `motionAround` 是左上角。设 `motionAround: 'center'`（或元素 `around: 'center'`）让中心贴路径。
- **Robot 帧错位 / 帧数对不上**
  检查 `size` 与雪碧图实际帧宽一致，且 `图片宽 / 帧宽` 为整数（多行布局时）；`total` 要等于真实帧数，多余帧会按换行规则继续剪辑出空白。
- **Robot 销毁后仍有定时器在跑**
  循环动作靠递归 `setTimeout`，`destroy()` 不会自动停链。销毁前 `pause()` 并清掉内部 `__timer`（见本课 `dispose()`）。

## 总结回顾

摘要：

`@leafer-in/motion-path` 把设了 `motionPath: true` 的元素变成路径提供者，同级兄弟用 `motion`（数字 = 绝对距离、`{type:'percent',value}` = 比例）贴着路径走，`motionRotation`（默认 `true`）控制是否随切线转向、`motionAround` 控制哪个点对齐路径；路径提供者自身设 `motion` 则变为描边生长。`@leafer-in/robot` 的 Robot 元素吃一张雪碧图（`robot: {url, size, total}`，帧从 0 起按行剪辑），用 `actions` 把帧组合成命名动作、`action` 切换，`play/pause/stop`、`now`、`FPS`、`loop` 控制播放。两者叠加即「精灵沿路径行走」。两个插件都必须显式引入，`leafer-ui` 本体只留空桩；循环动作的 `setTimeout` 不会随销毁自停，需手动清理。

一句话：

> `motionPath:true` 标记路径、`motion` 驱动跟随者，`robot` 定义帧图、`actions`/`action` 切换动作。

知识要点：

- 运动路径的「提供者」和「跟随者」是什么关系？跟随者要放在路径的什么位置？
- `motion` 的数字与百分比写法有何区别？默认值是什么？
- `motionRotation` 的 `true` / `false` / 数字三种取值各自什么效果？默认是哪个？
- 路径提供者自身设 `motion` 会发生什么（生长路径）？
- Robot 的 `robot` 雪碧图如何按帧编号剪辑？`actions` 的数字 / 数组 / 对象三种写法区别？
- 为什么必须显式引入两个插件？Robot 销毁时还要额外清理什么？
