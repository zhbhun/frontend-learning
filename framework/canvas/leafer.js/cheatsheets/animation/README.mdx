# 动画系统

`@leafer-in/animate` 给 UI 节点装上命令式关键帧动画。核心只有三层对象，配合方式固定且可预测：

- **关键帧（keyframe）** 描述「动画到什么样式」。单关键帧时引擎自动以节点当前状态为起点（from）、关键帧样式为终点（to）；多关键帧时按帧顺序逐段插值。
- **`node.animate(keyframe, options)`** 是入口，返回一个 **`Animate` 实例**（实现 `IAnimate`）。options 控制时长、曲线、循环、排队。
- **`Animate` 实例** 负责播放控制（`play` / `pause` / `stop` / `seek`）并发出动画事件（`UPDATE` / `COMPLETED` …）。

一句话建立直觉：**改关键帧改「去哪」，改 options 改「怎么去、去几次」，拿到返回的 Animate 实例决定「现在播到哪、是否暂停」**。

它和相邻能力有明确分工：`transition` 是声明式属性过渡，常配合 `@leafer-in/state` 的交互状态使用（见「过渡与状态」一课）；`animate()` 是命令式关键帧动画，可编程控制播放、循环和事件。沿路径运动与精灵帧动画由 `@leafer-in/motion` 承担（见「运动路径与精灵帧」一课）。

**前置：** 必须副作用引入插件，它才会在 UI 原型上注册 `animate` / `killAnimate` 方法与 `transition` 属性。

```ts
import '@leafer-in/animate'; // 注册动画能力，缺这行 node.animate 不存在
```

## 关键输入与默认值

`options` 即 `IAnimateOptions`（也兼容 `ITransition`：直接传时长数字、曲线名、或布尔）。下表是回查要点，默认值来自 `@leafer-in/animate` 2.2.9 源码。

| 选项 | 默认值 | 含义与回查要点 |
| --- | --- | --- |
| `duration` | `0.2`（秒） | 单段动画时长，不含 `delay` 与循环时间。太短会像瞬变，常被误判「动画没生效」。 |
| `easing` | `'ease'` | 缓动曲线名（或自定义）。见「动画曲线」小节。 |
| `delay` | `0` | 首次播放前的等待时间（秒）。 |
| `loop` | `false` | `true` 无限循环；数字 `N` 播放 N 次后停止；`false` 播一次。 |
| `swing` | `false` | 往返：到终点后反向回走。`true` 无限往返；数字为往返次数。 |
| `loopDelay` | `0` | 每次循环重新开始前的等待时间（秒）。 |
| `ending` | `'auto'` | 结束停留样式：`'from'`（起点）/ `'to'`（终点）/ `'auto'`（按方向自动）。 |
| `reverse` | `false` | 反向播放（to → from）。 |
| `speed` | `1` | 播放倍速；`2` 表示 wall-clock 时间减半。 |
| `autoplay` | `true` | 创建后是否立即播放。 |
| `join` | `false`（多帧时） | 把节点动画前状态作为第一帧 from。**单关键帧时强制为 `true`**。 |
| `attrs` | 全部属性 | 限定参与动画的属性白名单。 |

## 创建动画：关键帧与 animate()

`node.animate(keyframe, options)` 返回 `Animate` 实例。最常见的是**单关键帧**——传一个目标样式对象，引擎自动从节点当前状态插值到该样式：

```ts
import '@leafer-in/animate';
import { Leafer, Rect } from 'leafer-ui';

const leafer = new Leafer({ view: canvas, fill: '#f8fafc' });
const rect = new Rect({ x: 60, y: 120, width: 60, height: 60, cornerRadius: 16, fill: '#6366f1' });
leafer.add(rect);

// 单关键帧：from = 当前 {x:60, rotation:0}，to = {x:420, rotation:360}
const animate = rect.animate({ x: 420, rotation: 360 }, { duration: 1.5, easing: 'ease' });
```

需要经过多个中间状态时，传**关键帧数组**。每个关键帧可以是一个纯样式对象，也可以用 `{ style, duration, easing, delay, swing, loop }` 携带本段专属参数：

```ts
rect.animate([
  { x: 60, rotation: 0 },                                      // 第 0 帧：起点样式
  { style: { x: 240, rotation: 180 }, duration: 0.4 },         // 第 1 帧：带本段时长
  { style: { x: 420, rotation: 360 }, easing: 'bounce-out' },  // 第 2 帧：带本段曲线
], { duration: 1.2, easing: 'ease', loop: true });
```

多关键帧的两个边界要记住：**默认以第一帧样式作为起点**（不是节点当前状态），除非设 `join: true`；未指定时长的段由全局 `duration` 按 `autoDuration` 权重（默认每段权重 1）分配。

## 动画曲线：easing

`easing` 是一个「进度 → 进度」的映射函数：输入线性时间比 `t`（0 到 1），输出实际插值比。它不改终点，只改**到达终点的节奏**。曲线分四类直觉：

| 曲线族 | 成员（均有 `-in` / `-out` / `-in-out`） | 节奏直觉 |
| --- | --- | --- |
| 基础 | `linear`、`ease`、`ease-in` / `ease-out` / `ease-in-out` | `linear` 匀速；`ease*` 两端缓、中间快 |
| 幂函数 | `sine-*` / `quad-*` / `cubic-*` / `quart-*` / `quint-*` / `expo-*` / `circ-*` | 幂次越高，起步或收尾越陡；`-in` 起步慢加速，`-out` 快速减速到停 |
| 过冲 | `back-*`（单次回弹）、`elastic-*`（多次衰减抖动）、`bounce-*`（重力弹跳） | 越过终点再回落，适合强调动效 |
| 自定义 | `cubic-bezier`、`steps` | 三次贝塞尔四参数；阶梯跳变 |

在上方实例里把「动画曲线」依次切到 `linear`、`ease-out`、`back-out`、`bounce-out`、`elastic-out`，能直接看出匀速、减速、回弹、弹跳、抖动的区别。

两种自定义写法：

```ts
// 三次贝塞尔：四个控制点（同 CSS 的 cubic-bezier）
rect.animate({ x: 420 }, { easing: { name: 'cubic-bezier', value: [0.34, 1.56, 0.64, 1] } });

// 阶梯：分成 N 段跳变，可选取整方式 'floor' | 'round' | 'ceil'
rect.animate({ x: 420 }, { easing: { name: 'steps', value: [5, 'floor'] } });

// 注册一个可复用曲线名，之后像命名曲线一样用
import { AnimateEasing } from '@leafer-in/animate';
AnimateEasing.register('pop', (t: number) => 1 - Math.pow(1 - t, 3));
rect.animate({ x: 420 }, { easing: 'pop' });
```

边界：**多关键帧时 `easing` 可逐帧指定**（写在每帧的 `style` 同级）；某帧未指定时沿用全局 `easing`。

## 循环与排队：loop / swing / delay

「播一次」之外，`loop` 和 `swing` 控制重复，二者都支持 `true`（无限）/ 数字（次数）/ `false`（关）：

- `loop: true` —— 到达终点后立刻从头再来，无限循环。
- `swing: true` —— 到达终点后**反向**回走（to → from → to …），无限往返；`swing: 2` 表示往返 2 次。
- `loop: 3` —— 重复播放 3 次后停止并 `completed`。

`delay` 是首次播放前的等待，`loopDelay` 是每次循环重启前的等待。`ending` 决定动画结束后元素停在哪一端：`'to'`（终点）、`'from'`（起点）、`'auto'`（默认，按方向推断，往返场景下会自动选）。

```ts
// 弹球感：到终点弹回起点，无限往返，每次循环前停顿 0.2s
rect.animate({ x: 420 }, { duration: 1, easing: 'bounce-out', swing: true, loopDelay: 0.2 });

// 强制停在起点：ending 'from'
rect.animate({ x: 420 }, { duration: 1, ending: 'from' });
```

**一个高频陷阱：再次调用 `animate()` 默认是「排队」而不是「替换」。** 引擎会把旧动画和新动画放进一个 `AnimateList` 里依次执行。要替换必须先清除旧动画：

```ts
rect.killAnimate();          // 销毁当前动画并把 __animate 置空（推荐）
// 或
rect.animate()?.kill(true);  // 强行完成并销毁
rect.animate({ x: 0 }, { duration: 1 }); // 此时是替换，不再排队
```

上方实例在「时长 / 曲线 / 循环」变化时就是用 `killAnimate` 清旧再建新，所以每次都从左端重新出发；切「排队方式」到 `loop` / `swing` 即可看到无限循环与往返的差异。

## 控制：播放与事件

`animate()` 返回的 `Animate` 实例实现 `IAnimate`，提供命令式控制与实时状态：

| 方法 / 属性 | 作用 |
| --- | --- |
| `play()` / `pause()` | 继续 / 暂停。 |
| `stop()` | 停止并触发完成（走到结束样式、发 `COMPLETED`）。 |
| `seek(time)` | 跳到指定时间（秒），或传 `{ type: 'percent', value: 0.5 }` 按百分比跳转。 |
| `kill(complete = true)` | 强行完成并销毁。 |
| `time` / `duration` | 当前播放时间 / 总时长（秒），`time / duration` 即进度。 |
| `running` / `completed` / `looped` | 是否运行中 / 是否已完成 / 已循环次数。 |

动画事件来自 `AnimateEvent`，可用 `on` 订阅，也可在 options 的 `event` 里内联回调：

```ts
import { AnimateEvent } from '@leafer-in/animate';

const a = rect.animate({ x: 420 }, { duration: 1.5 });
a.on(AnimateEvent.COMPLETED, () => console.log('结束'));
a.on(AnimateEvent.UPDATE, () => console.log('进度', a.time / a.duration));

// 或内联回调（无需 import AnimateEvent）
rect.animate({ x: 420 }, {
  duration: 1.5,
  event: { completed: () => console.log('结束') },
});
```

事件类型：`created`（创建）、`play` / `pause` / `stop` / `seek`（控制动作）、`update`（每帧插值）、`completed`（完成）。

上方实例的读数就是由 `UPDATE` / `PLAY` / `PAUSE` / `COMPLETED` 事件驱动——动画在跑才发 `UPDATE`，所以读数自然跟随，无需额外轮询；关掉「播放 / 暂停」即可看到状态切到「已暂停」、进度冻结。

注意 `completed` 是终态：**已完成的动画再 `play()` 不会从头播**（它已是完成态）。要重放需重建动画，或 `seek(0)` 后 `play()`。上方实例对 once 模式完成后再次按下「播放 / 暂停」做了重建处理，所以能从头重放。

## 最佳实践

- **一次 vs 循环 vs 往返**：强调单次过渡用 `loop: false`（默认）并配 `ease-out`；持续呼吸/闪烁用 `loop: true`；需要原路返回（如抽屉、开关）用 `swing: true`，配 `ending` 控制停在哪端。
- **复用实例 vs 重建**：参数不变、只需播放暂停时复用同一个 `Animate` 实例（`play` / `pause` / `seek`）；时长、曲线、关键帧变化时重建，重建前先 `killAnimate()`，否则旧动画会排队。
- **关键帧 vs transition**：写死的、可编程的多段轨迹用 `animate()` 关键帧；跟随交互状态（hover/press/命名状态）的属性过渡用 `transition` + `@leafer-in/state`，更声明式。
- **可控进度**：需要拖动时间轴、回放时，用 `seek`；不要靠反复重建来模拟跳转，`seek` 更平滑且不重置循环计数。

## 常见问题

- **`node.animate is not a function` / 动画完全没反应**
  忘了 `import '@leafer-in/animate'`，`animate` 方法不会被注册。先确认副作用导入在入口执行。
- **动画看起来像瞬变、一闪而过**
  没传 `duration`，用的是默认 `0.2` 秒。显式给 `duration`（秒）。
- **连续调用 `animate()` 动画排队、越积越多，没有按预期替换**
  这是默认排队行为。每次重建前调 `killAnimate()`（或 `animate()?.kill(true)`）清掉旧动画。
- **往返 / 循环结束后元素停在了错误的一端**
  检查 `ending`：`'auto'`（默认）会按 `swing` / `reverse` 方向推断终点；需要固定就显式设 `'to'` 或 `'from'`。
- **动画播完后再 `play()` 没反应**
  `completed` 是终态，`play()` 只能继续未完成的动画。重放请重建动画，或 `seek(0)` 后再 `play()`。

## 总结回顾

摘要：

`@leafer-in/animate` 用 `node.animate(keyframe, options)` 把关键帧变成动画：单关键帧自动以当前状态为 from，多关键帧按帧顺序逐段插值（第一帧样式默认即起点，`join: true` 才用当前状态）。`options` 的 `duration` / `easing` / `delay` 决定单段节奏，`loop` / `swing` / `loopDelay` / `ending` 决定重复与落点。返回的 `Animate` 实例提供 `play` / `pause` / `stop` / `seek` 控制与 `UPDATE` / `COMPLETED` 等事件，实时状态可从 `time` / `running` / `completed` / `looped` 读取。再次 `animate()` 默认排队，替换前要 `killAnimate()`。

一句话：

> 关键帧写「去哪」，options 写「怎么去、去几次」，Animate 实例写「现在播到哪」。

知识要点：

- `animate(keyframe, options)` 的 keyframe 单帧与多帧写法有何区别？第一帧起点由什么决定？
- `duration` / `easing` / `loop` / `swing` / `delay` / `ending` 各自的默认值和作用？
- `easing` 有哪几类曲线，`-in` / `-out` / `-in-out` 与 `back` / `elastic` / `bounce` 的节奏差异？
- 如何替换一个正在播的动画而不让它排队？
- 如何读出动画进度、监听完成？已完成的动画为何再 `play()` 不重播，怎么重放？
