# 基础图形

LeaferJS 的基础图形是一组从 `UI` 基类派生的叶子节点，用 `new` 构造后通过 `leafer.add()` 挂到节点树即自动渲染。真正存在的图形类只有五个：`Rect`（矩形）、`Ellipse`（椭圆）、`Line`（线）、`Polygon`（多边形）、`Star`（星形）。它们各自用一个**区别性属性**定义形状——`width/height`、直径、`points/width`、`sides`、`corners`——其余外观（填充、描边、变换、阴影）由共用的 `UI` 能力统一提供。

理解这一点后，两个常见概念就能对号入座：**「圆」是 `Ellipse` 的特例**（X、Y 直径相等），**「折线」是 `Line` 的 `points` 模式**。LeaferJS 没有独立的 `Circle`、`Polyline` 类，所以你不会在 `leafer-ui` 的导出里找到它们。下面的实例用一个切换器把整个家族放在同一画布里，左下角「实际类」读数会明确告诉你每个概念背后真正实例化的是哪个类。

| 关键输入 | 默认 | 含义与回查要点 |
| --- | --- | --- |
| `fill` | 无（透明） | 闭合图形的填充色。不设置则只有描边、内部透明。 |
| `stroke` / `strokeWidth` | 无 / 0 | 描边色与粗细。线类图形必须设 `stroke` 才可见。 |
| `width` / `height` | 0 | 矩形宽高、椭圆的 X/Y **直径**、多边形与星形的外接尺寸；非 0 才有可见图形。 |
| `cornerRadius` | 0 | 圆角。`Rect` 可传 `number[]` 分设四角，`Polygon/Star/折线` 仅平滑拐角；圆/椭圆/两点直线忽略。 |
| `sides`（Polygon） | — | 正多边形边数，≥3；引擎在虚拟圆上每 `360/sides` 度取点连成。 |
| `corners`（Star） | — | 星形角数，≥3；与 `sides` 同属「按数量定义的正图形」。 |
| `innerRadius`（Star） | 0.382 | 星形内半径比例（0~1），控制凹度；越大越接近正多边形。 |
| `points`（Line/Polygon） | — | `[x1,y1, x2,y2, ...]` 坐标组，进入折线 / 自由多边形模式。 |
| `curve`（Line/Polygon） | false | 折线/多边形是否平滑；传 `number`（0~1）控制曲率，省略时按 0.5。 |
| `startAngle` / `endAngle`（Ellipse） | 完整椭圆 | 切扇形/弧线时设置，文档取值范围 -180~180。 |

## 图形家族

五个图形类共享同一套工作方式：`new 图形类({ 尺寸属性, fill, stroke, ... })` 创建节点，`leafer.add(node)` 挂载，引擎随即渲染。选择用哪个类，取决于你想用什么属性来定义形状——用宽高画 `Rect`，用直径画 `Ellipse`，用长度或点序列画 `Line`，用边数画 `Polygon`，用角数画 `Star`。

### Rect

矩形用 `width`、`height` 定义，`cornerRadius` 做圆角。它是最基础也最常用的图形，`Image`、`Canvas` 等元素都继承自 `Rect`。

```ts
import { Leafer, Rect } from 'leafer-ui'

const leafer = new Leafer({ view: window })

// 圆角矩形：cornerRadius 可为单值或数组
new Rect({ width: 100, height: 100, cornerRadius: 20, fill: '#32cd79' })
// 四角分别设置：[topLeft, topRight, bottomRight, bottomLeft]
new Rect({ width: 100, height: 100, cornerRadius: [0, 40, 20, 40], fill: '#32cd79' })
```

`cornerRadius` 数组按 CSS 风格缺省复制：`[20, 10, 20]` 表示「左上、右上/左下、右下」，`[20, 10]` 表示「左上/右下、右上/左下」。坐标原点 `(x, y)` 默认在矩形左上角，想以中心定位可配合 `around: 'center'`（见「变换」课）。

### Ellipse（含圆）

椭圆没有 `radiusX/radiusY`，**尺寸由 `width`（X 轴直径）、`height`（Y 轴直径）决定，圆心位于 `width/2, height/2`**。令两者相等就是正圆——这正是 LeaferJS 表达「圆」的方式。

```ts
import { Leafer, Ellipse } from 'leafer-ui'

const leafer = new Leafer({ view: window })

// 圆：X、Y 直径相等
new Ellipse({ width: 100, height: 100, fill: '#32cd79' })
// 椭圆：直径不等
new Ellipse({ width: 50, height: 100, fill: '#32cd79' })
```

把 `startAngle`/`endAngle`（-180~180）从完整范围收窄，再配合 `innerRadius`（0~1 内半径比例），同一个类还能画扇形、圆环、扇形圆环和弧线。默认不传角度时绘制完整椭圆。

### Line（含直线与折线）

`Line` 一个类承担两种形态。**两点直线**用 `width`（长度）加可选的 `rotation`，或直接给计算属性 `toPoint`（目标点，相对元素起点）自动换算长度与角度；**折线**进入 `points` 模式，用坐标组 `[x1,y1, x2,y2, ...]` 描述任意折线，`curve` 平滑、`closed` 闭合、`cornerRadius` 圆滑拐角。LeaferJS 没有 `Polyline` 类，折线就是 `Line`。

```ts
import { Leafer, Line } from 'leafer-ui'

const leafer = new Leafer({ view: window })

// 两点直线：width 为长度，必须设 stroke 才可见
new Line({ width: 100, strokeWidth: 5, stroke: '#32cd79' })
// 到目标点的直线（toPoint 相对起点，自动换算 width 与 rotation）
new Line({ toPoint: { x: 100, y: 50 }, strokeWidth: 5, stroke: '#32cd79' })
// 折线：points 模式
new Line({
  points: [10, 90, 10, 10, 50, 70, 90, 10, 90, 90], // [x,y, x,y ...]
  cornerRadius: 5,
  strokeWidth: 5,
  stroke: '#32cd79',
})
```

线类图形不靠 `fill` 显示，必须设置 `stroke`（和 `strokeWidth`），否则什么都不画。`toPoint` 是计算属性：读取时会根据当前的 `width` 与 `rotation` 反算出来。

### Polygon

正多边形用 `width`、`height` 加 `sides`（边数 ≥3）定义，内部在一个虚拟圆上每 `360/sides` 度取点连成。给它 `points` 就进入**自由多边形**模式，按坐标组画出任意多边形，同样支持 `curve` 平滑与 `cornerRadius`。三角形、菱形、五边形都由 `sides` 一个值切换。

```ts
import { Leafer, Polygon } from 'leafer-ui'

const leafer = new Leafer({ view: window })

// 正多边形：sides 控制边数
new Polygon({ width: 100, height: 100, sides: 5, fill: '#32cd79' })
// 自由多边形：points 模式
new Polygon({ points: [10, 90, 10, 10, 50, 70, 90, 10, 90, 90], fill: '#32cd79' })
```

### Star

星形与 `Polygon` 同属「按数量定义的正图形」，把 `sides` 换成 `corners`（角数 ≥3），再用 `innerRadius`（内半径比例，默认 `0.382`）控制凹度——越接近 1 越像正多边形，越小越尖锐。`cornerRadius` 同样能让拐角圆滑。

```ts
import { Leafer, Star } from 'leafer-ui'

const leafer = new Leafer({ view: window })

// 五角星：corners=5，innerRadius 用默认值
new Star({ width: 100, height: 100, corners: 5, fill: '#32cd79' })
// 改变凹度
new Star({ width: 100, height: 100, corners: 8, innerRadius: 0.5, fill: '#32cd79' })
```

## 最佳实践

- **按「用什么属性定义形状」选类。** 已知宽高用 `Rect`，已知直径用 `Ellipse`（圆只是它的特例），已知两端用 `Line` 的 `toPoint`，已知点序列用 `Line`/`Polygon` 的 `points`，已知边数用 `Polygon`、角数用 `Star`。不要为「画一个圆」去找 `Circle` 类。
- **自由轮廓优先用 `points`，正图形优先用数量。** 规则的三角形/五边形/星形用 `sides`/`corners` 更稳定、可复现；只有不规则轮廓才手写 `points` 坐标组。需要 SVG 路径语法或命令式逐笔绘制时，改用 `Path` / `Pen`（见「路径与画笔」课）。
- **闭合图形配 `fill`，线类配 `stroke`。** 忘记 `fill` 的矩形和忘记 `stroke` 的直线都会「看不见」，这是最常见的「为什么没渲染」原因。

## 常见问题

- **为什么找不到 `Circle` / `Polyline` 类？**
  它们不存在。圆用 `Ellipse`（`width === height`），折线用 `Line` 的 `points` 模式。`leafer-ui` 只导出 `Rect`、`Ellipse`、`Line`、`Polygon`、`Star` 等图形类。
- **给 `Ellipse` 设 `radiusX` / `radiusY` 没生效？**
  `Ellipse` 没有 `radius` 系属性，尺寸由 `width`（X 直径）、`height`（Y 直径）决定，圆心在 `width/2, height/2`。
- **`Line` 设了 `fill` 还是看不到？**
  线类图形只用 `stroke`（配合 `strokeWidth`）描出，`fill` 不参与。两点直线若忘记 `stroke`、或 `width` 为 0，都会什么都不画。
- **折线 / 多边形的点坐标是相对哪里？**
  相对元素自身的坐标原点（默认左上角）。需要整体定位时用 `x/y` 平移，或用 `around: 'center'` 把原点移到包围盒中心再给画布中心坐标（见「变换」课）。

## 总结回顾

摘要：

LeaferJS 的基础图形是五个 `UI` 子类：`Rect`、`Ellipse`、`Line`、`Polygon`、`Star`，用 `new` 构造、`leafer.add()` 挂载即渲染。每个类靠一个区别性属性定义形状——宽高、直径、长度或点序列、边数、角数——填充、描边、圆角、变换等外观由共用的 `UI` 能力统一承担。「圆」是 `Ellipse` 的等直径特例、「折线」是 `Line` 的 `points` 模式，二者没有独立类。`Polygon` 和 `Star` 还能切到 `points` 模式画自由轮廓，`Ellipse` 能用角度切出扇形与圆环。

一句话：

> 记住五个类和它们各自的「定义属性」——圆归 `Ellipse`、折线归 `Line`，其余按宽高、边数、角数对号入座。

知识要点：

- LeaferJS 有哪些基础图形类？分别用什么属性定义形状？
- 「圆」和「折线」在 API 中如何表达？
- `Ellipse` 的尺寸用 `radius` 还是 `width/height`？
- `Line` 的两点直线和折线分别怎么写？为什么必须设 `stroke`？
- `Polygon` 的 `sides` 与 `Star` 的 `corners` 各自控制什么？
