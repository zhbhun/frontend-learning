# 变换

每个显示对象都带一个**局部变换**，负责把对象自身的局部坐标映射到父坐标系。本课讲清组成这个变换的六个属性——`position`、`scale`、`rotation`、`pivot`、`skew`、`anchor`——各做什么、默认值是多少、怎样组合，以及变换怎样沿父子链叠加成世界变换。读完你能预测：改其中任意一个，对象会怎么动。

v8 里 `Container` 是所有场景对象的基类（取代旧的 `DisplayObject`），所以下表前五项所有场景对象都有；`anchor` 只属于纹理类叶子节点。场景图本身的父子关系是「场景图与容器」课的内容，本课只讲变换如何沿父子链叠加。

| 属性 | 默认值 | 单位 | 适用对象 | 作用 |
| --- | --- | --- | --- | --- |
| `position` | `(0, 0)` | 像素 | 所有场景对象 | 局部原点在父坐标系的位置；`x` / `y` 是快捷属性 |
| `scale` | `(1, 1)` | 倍数 | 所有场景对象 | 围绕 `pivot` 缩放，`1.0` 为原始尺寸，负值翻转 |
| `rotation` | `0` | 弧度（顺时针） | 所有场景对象 | 围绕 `pivot` 旋转；`angle` 是度数别名（0~360） |
| `pivot` | `(0, 0)` | 像素 | 所有场景对象 | `scale` / `rotation` / `skew` 的中心点；设置会视觉移动对象 |
| `skew` | `(0, 0)` | 弧度 | 所有场景对象 | 围绕 `pivot` 倾斜，类似 CSS `skew()` |
| `anchor` | `(0, 0)` | 归一化 0~1 | 纹理类叶子节点（`Sprite`、`Text` 等） | 纹理的哪一点对齐到局部原点，兼作旋转中心 |

> 因为画布 y 轴向下，`rotation` 正值是**顺时针**；`angle` 与 `rotation` 联动，改一个另一个同步。

## 位置

`position` 是对象局部原点 `(0, 0)` 在父坐标系中的落点——最常用、最直观的属性。`x` / `y` 是它的快捷属性，两者等价。

```ts
sprite.position.set(120, 80);
// 等价于直接读写 x / y
sprite.x = 120;
sprite.y = 80;
```

`position` 是局部变换的**最外层平移**：对象的其余变换（围绕 `pivot` 的缩放、旋转、倾斜）都发生在 `position` 处。所以「对象放在哪」由 `position` 决定，「放在那里之后长什么样」由其余属性决定。`position` 的效果可以在下方「变换中心」范例的 `position.x` / `position.y` 控件里直接观察。

## 变换中心

`scale`、`rotation`、`skew` 都「围绕 `pivot`」进行。`pivot` 是对象局部坐标系里的一个点，单位是像素，默认 `(0, 0)`，所有场景对象都有。

关键认知：**设 `pivot` 会视觉移动对象**。这与 CSS 的 `transform-origin` 不同——CSS 改 `transform-origin` 不影响元素位置，PixiJS 改 `pivot` 会让对象整体偏移。原因是 `pivot` 的语义是「把局部坐标系的哪一点对齐到 `position`」：`pivot` 变了，对象内容相对 `position` 的位置就变了。

下面这个范例把 `position`、`scale`、`rotation`、`pivot`、`skew` 同放一个 `Graphics` 上。红色十字标记 `pivot` 的世界位置——它恰好等于对象的 `position`，即旋转中心。`Graphics` 没有 `anchor`（只有纹理类叶子节点才有），正好演示「非纹理对象用 `pivot`」。

| 调 `pivot.x` / `pivot.y` | 矩形相对红色十字偏移（对象被「移动」了），十字本身不动 |

| 调 `skew.x` / `skew.y` | 矩形围绕红色十字倾斜错切 |
| 调 `position.x` / `position.y` | 红色十字连同矩形一起移动到新位置 |

对 `Container`、`Graphics` 这类没有 `anchor` 的对象，「以中心旋转」的做法是先把 `pivot` 设到几何中心，再让 `position` 落到目标位置：

```ts
// 先拿到局部包围盒（局部坐标系里的尺寸），把 pivot 设到中心
const bounds = graphics.getLocalBounds();
graphics.pivot.set(bounds.width / 2, bounds.height / 2);
// pivot 一设，对象会偏移，用 position 把它放回想要的位置
graphics.position.set(centerX, centerY);
graphics.rotation = Math.PI / 4; // 围绕中心顺时针转 45°
```

## 形变

`scale`、`rotation`、`skew` 三者共享同一个模型：**都围绕 `pivot` 改变对象形状**，组合顺序固定（PixiJS 内部按「倾斜 → 缩放 → 旋转」围绕 `pivot` 计算，再平移到 `position`）。它们的效果都在上方「变换中心」范例里，调对应控件即可观察。

### 缩放

`scale` 围绕 `pivot` 缩放，`(1, 1)` 为原始尺寸，`x` / `y` 可独立设。负值实现翻转：`scale.x = -1` 水平翻转，`scale.y = -1` 垂直翻转，翻转会作用到整个子树。

需要区分：`scale` 是变换属性，`width` / `height` 是由此派生的像素尺寸——设 `width` / `height` 实际改的是 `scale`（依据对象局部包围盒换算）。`width` / `height` 的细节归「内容对象」相关课程，这里只记结论。

### 旋转

`rotation` 围绕 `pivot` 顺时针旋转，单位**弧度**，一圈为 `2 * Math.PI`。`angle` 是它的**度数**别名（0~360），两者联动：

```ts
sprite.rotation = Math.PI / 4; // 顺时针 45°
sprite.angle = 45;             // 等价写法，度数更直观
```

### 倾斜

`skew` 围绕 `pivot` 倾斜对象，单位弧度，行为类似 CSS `skew()`：`skew.x` 沿 x 方向错切，`skew.y` 沿 y 方向错切，两者可叠加成平行四边形。它用得比 `position` / `scale` / `rotation` 少，但在做伪 3D 倾斜、剪切效果时很直接——在上方范例调 `skew.x` / `skew.y` 即可看到。

## 锚点

`anchor` 只存在于**纹理类叶子节点**——`Sprite`、`Text`、`AnimatedSprite`、`BitmapText`、`HTMLText`、`TilingSprite`、`NineSliceSprite` 等「有纹理」的对象。它用归一化值（0~1）表示纹理的哪一点对齐到对象的局部原点：`(0, 0)` 是纹理左上角，`(0.5, 0.5)` 是纹理中心，`(1, 1)` 是右下角。

`anchor` 同时做两件事：把纹理内容偏移到对应位置，并把旋转 / 缩放中心隐式设到那里。所以对 `Sprite`「以中心旋转」最简写法是 `anchor.set(0.5)`，不必算像素尺寸：

```ts
sprite.anchor.set(0.5);             // 纹理中心对齐到局部原点（= position）
sprite.position.set(centerX, centerY);
sprite.rotation = Math.PI / 4;      // 围绕中心顺时针转 45°
```

| 读者操作 | 可观察证据 |
| --- | --- |
| 调 `anchor.x` / `anchor.y` 从 `0` 到 `1` | 纹理相对红色十字（= `position`）从左上滑到右下；旋转中心随之内移 |
| 调 `rotation` | 纹理围绕「anchor 对齐点」（即 `position`）旋转 |

`anchor` 与 `pivot` 是本课最易混的两个点，关键区别：

| 维度 | `anchor` | `pivot` |
| --- | --- | --- |
| 单位 | 归一化 `0~1` | 像素 |
| 适用 | 纹理类叶子节点 | 所有场景对象 |
| 语义 | 纹理内容原点（移动的是内容） | 变换原点（移动的是变换中心，不动内容） |
| 居中写法 | `anchor.set(0.5)` | `pivot.set(width / 2, height / 2)` |

对同一个 `Sprite`，设 `anchor = (0.5, 0.5)` 与设 `pivot = (w / 2, h / 2)`（`w` / `h` 为纹理像素尺寸）都能实现「围绕中心旋转」。差别在于 `anchor` 同时让纹理中心对齐到 `position`，而 `pivot` 不移动纹理、只改旋转中心。

## 变换组合与父子继承

单个对象的局部变换，按「围绕 `pivot` 做 skew / scale / rotation，再平移到 `position`」组合，等价于一个 2D 仿射矩阵（PixiJS 内部的 `localTransform`）。`anchor` 不直接进这个矩阵，而是通过挪动纹理内容来改变「内容相对局部原点」的位置。

变换会沿场景图父子链**相乘**：子对象的世界变换 = 父世界变换 × 子局部变换。所以父容器旋转 / 缩放 / 平移，所有子孙跟着变；子对象的 `position` 始终在**父坐标系**里度量。

读数「子局部位置」是 `position` 在父坐标系里的值，「子世界位置」是它经父变换后的最终落点——两者差异正是父变换的贡献。利用这一点，把多个对象放进同一个父 `Container`，对父容器施加一次变换，就能统一移动 / 旋转 / 缩放整组对象。

## 常见问题

- 设了 `pivot` 或 `anchor` 后对象「跑偏」了。
  这是预期行为：`pivot` / `anchor` 都会视觉移动对象（与 CSS `transform-origin` 不同）。处理方式：要么按偏移量反向补偿 `position`，要么直接把 `pivot` / `anchor` 设到想要的原点，再让 `position` 落到目标位置。判断依据：范例里红色十字始终是 `position`（旋转中心），调 `pivot` / `anchor` 时十字不动、对象内容相对它位移。

- `Sprite` 以中心旋转，用 `anchor` 还是 `pivot`？
  `Sprite` 用 `anchor.set(0.5)` 最简——直接把纹理中心对齐到 `position`，不用算像素。`Container`、`Graphics` 等没有 `anchor`，用 `pivot.set(width / 2, height / 2)`（需先知道几何尺寸，可从 `getLocalBounds()` 取）。

- `scale` 设负值翻转后，子对象或文字朝向也反了。
  负 `scale` 会翻转对象及其整个子树。若只想翻转纹理、不想影响子节点，把翻转做在叶子 `Sprite` 上，而不要做在父容器上。

## 总结回顾

摘要：

PixiJS 每个显示对象有一个局部变换，由 `position`（最外层平移）加上围绕 `pivot` 的 `scale`、`rotation`、`skew` 组合而成；纹理类叶子节点还能用 `anchor` 设定内容原点。`pivot` 和 `anchor` 都会视觉移动对象；`scale` / `rotation` / `skew` 始终围绕 `pivot`；`anchor` 用归一化值、只作用于纹理类对象，`pivot` 用像素、作用于所有对象。变换沿父子链相乘，子的 `position` 在父坐标系里度量，父级变换叠加到所有子孙。

一句话：

> `position` 决定对象放在父坐标系的哪里，`pivot` 决定其余变换围绕哪个点；纹理类对象用 `anchor` 设内容原点，所有变换沿父子链相乘。

知识要点：

- 六个变换属性各自的默认值、单位和适用对象是什么？
- 设 `pivot` 或 `anchor` 后对象为什么会移动？与 CSS `transform-origin` 有何不同？
- `scale` / `rotation` / `skew` 围绕哪个点？`Sprite` 居中旋转最简写法是什么？
- `anchor` 和 `pivot` 在单位、适用对象和语义上有什么区别？
- 子对象的世界变换如何由父变换和子局部变换得到？
