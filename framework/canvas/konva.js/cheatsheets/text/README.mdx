# 文本

`Konva.Text` 把字符串画到 canvas 上，但它不像矩形那样「宽高就是图形」——它是一个带**文本框**的形状：`width` 与 `height` 定义一个排版区域，文字在里面按字体、对齐和换行规则流动。理解了「`width` 决定换行、`height` 决定截断」，本课的所有属性就都通了。

最值得先建立的直觉是**自适应**：`width`/`height` 默认都是 `auto`，文本框会缩到刚好包住内容——一行文字时框宽就等于这行文字宽，不设 `width` 就不会换行。只有当你显式给出 `width`，文字才会按 `wrap` 规则折成多行；再给出 `height`，超出的部分才能配合 `ellipsis` 截断成「…」。文本测量方法（`getTextWidth()`、`width()`、`height()`）则告诉你内容到底占多大、框到底多大。

`Konva.Text` 继承自 `Konva.Shape`，填充、描边、阴影等共享能力见「[填充、描边与阴影](?path=/docs/fill-stroke--docs)」。本课只聚焦文本特有的内容、字体、排版与测量。常用属性与默认值（已与 Konva 10.3 源码核对）：

| 属性 | 类型 | 默认值 | 作用 |
| --- | --- | --- | --- |
| `text` | `String` | `''` | 文本内容；`\n` 产生显式换行 |
| `fontFamily` | `String` | `'Arial'` | 字体族，多个用逗号分隔 |
| `fontSize` | `Number` | `12` | 字号，单位 px |
| `fontStyle` | `String` | `'normal'` | `'normal'` / `'italic'` / `'bold'` / `'500'` / `'italic bold'` |
| `fontVariant` | `String` | `'normal'` | `'normal'` 或 `'small-caps'` |
| `textDecoration` | `String` | `''` | `'underline'` / `'line-through'`，或两者空格并列 |
| `align` | `String` | `'left'` | `'left'` / `'center'` / `'right'` / `'justify'` |
| `verticalAlign` | `String` | `'top'` | `'top'` / `'middle'` / `'bottom'` |
| `lineHeight` | `Number` | `1` | 行高倍数，`lineHeightPx = lineHeight × fontSize` |
| `letterSpacing` | `Number` | `0` | 字间距，单位 px |
| `padding` | `Number` | `0` | 文本框四周内边距 |
| `wrap` | `String` | `'word'` | `'word'` / `'char'` / `'none'` |
| `ellipsis` | `Boolean` | `false` | 内容溢出时在末行加「…」，需固定 `width` 与 `height` |
| `width` | `Number \| 'auto'` | `auto` | 文本框宽（含 padding）；固定后才换行 |
| `height` | `Number \| 'auto'` | `auto` | 文本框高（含 padding）；固定后才截断 |
| `fill` | `String` | `'black'` | 文本颜色（未设渐变 / 图案时） |

## 内容与字体

创建文本和其它形状一样：`new Konva.Text({ ... })` 后 `layer.add(...)`。最常调的就是 `text`（内容）和几个字体属性。Stage 与 Layer 的搭建见「[安装与第一个场景](?path=/docs/first-scene--docs)」。

```ts
const label = new Konva.Text({
  x: 20,
  y: 20,
  text: 'Konva 文本',
  fontFamily: 'Arial',
  fontSize: 30,
  fontStyle: 'bold',          // 'italic'、'500'、'italic bold' 等
  fill: '#4f7cff',
});
layer.add(label);
```

几个容易忽略的点：

- `text` 默认是空字符串，`fill` 默认是 `'black'`（未设渐变 / 图案时由内部 `checkDefaultFill` 兜底）。忘记写 `text` 不会报错，但什么都画不出来。
- `fontStyle` 直接拼进 canvas 的 `font` 简写，所以 `'500'` 这类数字字重也生效；`'italic bold'` 这种组合写法也合法。
- `textDecoration` 支持把 `'underline'` 和 `'line-through'` 用空格连起来同时生效；留空（默认）则不画任何装饰线。
- 文本里写 `\n` 会**显式换行**；隐式换行（按词 / 字符折行）由下面的 `wrap` 控制。
- 几个进阶属性本课不展开：`direction`（`'inherit'` / `'rtl'`，控制 RTL 文本方向）、`underlineOffset`（微调下划线离基线的距离，默认按字号推算）、`charRenderFunc`（每个字符绘制前的回调钩子，可逐字改样式，但会关闭原生字距 / 连字）。需要时查 [API 文档](https://konvajs.org/api/Konva.Text.html)。

## 文本框、换行与截断

这是理解 `Konva.Text` 行为的关键。文本框有两条独立的尺寸轴，各自触发一种排版后果：

- **`width` 触发换行。** `width` 为 `auto` 时文字只排成「每段一行」（`\n` 除外），永远不会被折行。一旦固定 `width`，超出宽度的文字就按 `wrap` 规则拆成多行。
- **`height` 触发截断。** `height` 为 `auto` 时框高随行数增长，永远放得下。一旦固定 `height`，多出来的行被裁掉；此时 `ellipsis: true` 会在最后一行末尾补「…」。

| 切「换行 wrap」对比 `word` 与 `char` | `word` 尽量在空格 / 连字符处断行；`char` 在任意字符处断行 |
| 打开「省略号 ellipsis」并缩小「框高 height」 | 容不下的内容被裁掉，末行末尾出现「…」 |
| 切「水平对齐 align」 | 单行内文字相对框宽左 / 中 / 右移动 |
| 切「垂直对齐 verticalAlign」并放大「框高 height」 | 文字块相对框高停在顶 / 中 / 底 |
| 对比读数「最长行宽」与「完整一行宽」 | `wrap=none` 截断时最长行宽明显小于完整一行宽；`width` 足够大时两者接近相等 |

### wrap 换行模式

`wrap` 决定固定 `width` 之后怎样把一行长文字拆开，默认 `'word'`：

- **`'word'`（默认）**：优先在空格、连字符处断行；但若单个词本身比 `width` 还长，仍会按字符硬拆这个词。
- **`'char'`**：不看词边界，在任意字符处断行，适合 CJK 等无明显词分隔的文本。
- **`'none'`**：不折成多行，文字只占一行；超出 `width` 的部分**被截断丢弃**，不会溢出框外。配合 `ellipsis: true` 可在末尾补「…」表示有省略。

记住前提：换行只在**固定了 `width`** 时发生。`width` 为 `auto` 时，`wrap` 写成什么都不会折行。

### ellipsis 截断

`ellipsis: true` 让内容放不下时在末行末尾补「…」。它需要固定 `width`（截断发生在宽度方向），再分两种情况：

- **`wrap` 为 `'word'` / `'char'`**：文字会一直换行，直到**固定了 `height`** 把可用行数封顶，多出的行才判定为溢出并补「…」。这是官方「ellipsis 需同时限定 width 和 height」所指的常见场景。
- **`wrap: 'none'`**：文字只占一行，超 `width` 就触发省略号，不依赖 `height`。

实例里把「换行 wrap」留在 `word`、「框高 height」调到比内容所需更小、再打开「省略号 ellipsis」，就能看到末行的「…」。

## 对齐

对齐属性决定文字**在文本框内**的位置，因此都依赖框尺寸大于内容时才看得见效果。

`align` 控制水平方向，取值 `'left'`（默认）、`'center'`、`'right'`、`'justify'`。`'justify'` 只拉伸**非末行**——把每行（除段落最后一行外）的文字撑满框宽，与印刷排版一致。

`verticalAlign` 控制垂直方向，取值 `'top'`（默认）、`'middle'`、`'bottom'`。它只在 `height` **大于**实际内容高度时才有意义——`height` 为 `auto` 时框高刚好等于内容高，顶 / 中 / 底没有差别。实例里把「框高 height」调大、内容填不满时，切换该项即可看到文字块整体上下移动。

```ts
const note = new Konva.Text({
  x: 20,
  y: 20,
  width: 240,
  height: 120,                 // 固定后 verticalAlign 才有意义
  text: '固定框里的居中文字',
  align: 'center',
  verticalAlign: 'middle',
  fontSize: 18,
  padding: 8,
  fill: '#172033',
});
```

## 文本测量

Konva 提供几个公开方法读取文本的尺寸，它们在「内容多大、框多大、一行多宽」这几个问题上有明确分工：

| 方法 | 返回 | 含义 |
| --- | --- | --- |
| `getTextWidth()` | `Number` | **纯文本**最大行宽，不含 padding；即所有换行后最长那一行的文字宽 |
| `width()` | `Number` | 整个文本框宽，**含 padding**；`width` 为 auto 时 = `getTextWidth() + padding×2`，固定时 = 设定值 |
| `height()` | `Number` | 整个文本框高，**含 padding**；`height` 为 auto 时 = `fontSize × 行数 × lineHeight + padding×2`，固定时 = 设定值 |
| `measureSize(text)` | `{ width, height, ... }` | 用当前字体测量**单行**字符串，不能处理多行；返回值里还含 `actualBoundingBoxAscent` 等字身度量 |

实例读数里有三个测量值：`getTextWidth()`（换行 / 截断后最长一行的宽）、`measureSize(DEMO_TEXT).width`（完整文本排成一行的自然宽）和 `width()`（框宽）。最有用的对照是 `getTextWidth()` 与 `measureSize()`：

- `wrap='none'` 截断时，`getTextWidth()` 明显小于 `measureSize()`——被截掉的那部分文字宽度，就是两者之差。
- `wrap='word'` 折行后，`getTextWidth()` 是最长一行的宽，必然小于等于 `measureSize()`；`width` 足够大、文字只占一行时两者接近相等。
- `width()` 始终包含 padding，固定 `width` 时就等于设定值。

> `getTextHeight()` 已废弃，控制台会打印警告。需要整框高度用 `height()`，需要单行字高用 `fontSize()`。

测量常用来做「文字居中」和「按内容反推框尺寸」。例如把一段文字相对某点水平居中，可以用 `getTextWidth()`：

```ts
const title = new Konva.Text({ text: '标题', fontSize: 28, fill: '#1e293b' });
title.offsetX(title.getTextWidth() / 2);   // 让 x 落在文字水平中点
```

## 常见问题

- 设了 `wrap: 'none'`，超出宽度的文字「不见了」，也没有溢出到框外。
  这是预期行为：`Konva.Text` 永远把文字塞进 `width`，`wrap='none'` 的含义是「不折成多行、单行截断」，超出部分被丢弃而非溢出。若想在末尾看到「…」表示有省略，把 `ellipsis` 设为 `true`。

- 设了 `ellipsis: true`，但省略号始终不出现。
  先检查是否**同时固定了 `width` 与 `height`**。只固定 `width` 时文字会一直换行、永远放得下，没有「溢出」可触发省略号；只有再给 `height` 把可用行数封顶，多出的行才会被判定为溢出并补「…」。

## 总结回顾

摘要：

`Konva.Text` 是带「文本框」的形状：`width`/`height` 默认 `auto`，框缩到刚好包住内容。固定 `width` 后文字按 `wrap`（`'word'` 优先在词边界断行、`'char'` 任意字符断行、`'none'` 不换行、超出部分截断丢弃）拆开；同时固定 `width` 与 `height` 后，配合 `ellipsis` 能把溢出部分截成「…」。Konva.Text 永远把文字塞进 `width`，不会横向溢出框外。对齐分水平（`align`）与垂直（`verticalAlign`），后者只在框高大于内容时生效。测量上，`getTextWidth()` 给最长行纯文本宽、`measureSize()` 用当前字体测单行字符串的自然宽、`width()`/`height()` 给整框尺寸（含 padding），`getTextHeight()` 已废弃。实例用虚线框把「内容 vs 框」的关系同时呈现为视觉与读数。

一句话：

> `width` 决定换行、`height` 决定截断——文本框的这两条轴，是理解 `Konva.Text` 全部排版行为的钥匙。

知识要点：

- `width`/`height` 默认是什么？什么时候才会换行、什么时候才会截断？
- `wrap` 的三种模式各自怎样处理超出宽度的文字？
- `ellipsis` 生效需要同时固定哪两个属性？
- `align` 与 `verticalAlign` 各在什么前提下才看得出效果？`'justify'` 的特殊行为是什么？
- 想得到「纯文本宽（不含 padding）」「整框宽」「单行字符串的尺寸」分别用哪个方法？
