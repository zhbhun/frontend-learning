# 渐变与图案

Konva 的形状填充不止 `fill` 一种纯色。所有形状都继承自 `Konva.Shape`，因此都能用三种更丰富的填充：**线性渐变**、**径向渐变**与**图案**。这三者不是互斥开关——同一个形状可以同时挂上多套填充数据，由一个总属性 `fillPriority` 决定当前用哪一套。所以本课首先要讲清的不是某个渐变属性，而是 `fillPriority` 的选择逻辑：搞懂它，你才能预测"设了渐变属性之后，形状到底会显示什么"。

下面的实例给一个六边形同时配置了纯色、线性渐变、径向渐变、图案四套填充数据，再通过「fillPriority」控件在它们之间切换。默认停在 `'color'`——你会看到，尽管渐变与图案属性都已就位，形状仍显示纯色。这就是 `fillPriority` 在起作用。

四类填充的关键属性与 `fillPriority` 取值（共享默认值：`fillPriority` 为 `'color'`；渐变 / 图案属性不设时不生效）：

| 填充方式 | 关键属性 | `fillPriority` | 备注 |
| --- | --- | --- | --- |
| 纯色 | `fill` | `'color'`（默认） | 见「[填充、描边与阴影](?path=/docs/fill-stroke--docs)」 |
| 线性渐变 | `fillLinearGradientStartPoint` / `EndPoint` / `ColorStops` | `'linear-gradient'` | 起点 → 终点定义方向，坐标在形状本地系 |
| 径向渐变 | `fillRadialGradientStartPoint` / `StartRadius` / `EndPoint` / `EndRadius` / `ColorStops` | `'radial-gradient'` | 内圆 → 外圆 |
| 图案 | `fillPatternImage`、`fillPatternRepeat`、`fillPatternOffset`、`fillPatternScaleX` / `Y`、`fillPatternRotation` | `'pattern'` | `fillPatternRepeat` 默认 `'repeat'` |

所有渐变的 `ColorStops` 都是同一个格式：扁平的「偏移、颜色」交错数组，偏移量在 `0`–`1` 之间，例如 `[0, '#2563eb', 0.5, '#22d3ee', 1, '#a5f3fc']`。

## fillPriority 与填充选择

`fillPriority` 是填充的总开关，决定形状用四套填充数据里的哪一套。它的选择逻辑分两步，记住这两步就能预测一切：

1. **优先匹配**：若 `fillPriority` 指向的那套填充数据确实存在，直接用它。
2. **回退兜底**：若指向的数据缺失（例如 `fillPriority='linear-gradient'` 但没设 colorStops），按 `color → pattern → linear-gradient → radial-gradient` 的顺序，取第一个数据存在的填充。

关键陷阱：`fillPriority` 的默认值是 `'color'`。所以当你同时设了 `fill`（纯色）和渐变属性，却不显式声明 `fillPriority` 时，第一步就匹配到纯色，渐变被静默忽略——这是"设了渐变却不显示"最常见的原因。要么不设 `fill` 颜色（让回退兜底找到渐变），要么显式 `fillPriority('linear-gradient')`。

### 线性渐变

线性渐变由两点定义：`fillLinearGradientStartPoint` 和 `fillLinearGradientEndPoint`，colorStops 沿这条连线分布。两点坐标都在**形状本地坐标系**里：矩形的本地原点是其左上角（`x`/`y` 位置），圆与正多边形的本地原点是中心。

```ts
const rect = new Konva.Rect({
  x: 40, y: 40, width: 220, height: 120,
  fillPriority: 'linear-gradient',
  fillLinearGradientStartPoint: { x: 0, y: 0 },     // 本地坐标：矩形左上角
  fillLinearGradientEndPoint: { x: 220, y: 120 },   // 本地坐标：矩形右下角
  fillLinearGradientColorStops: [0, '#2563eb', 1, '#22d3ee'],
});
```

要旋转渐变方向，调整起点和终点的相对位置即可（例如改成 `{0, 0}` → `{220, 0}` 得到水平渐变）。超出起点—终点连线的区域，按 Canvas 规则用首、末色向两侧延伸填充。把实例切到 `linear-gradient`，能看到左上 → 右下的渐变方向。

### 径向渐变

径向渐变由两个圆定义：内圆（`fillRadialGradientStartPoint` + `fillRadialGradientStartRadius`）和外圆（`fillRadialGradientEndPoint` + `fillRadialGradientEndRadius`），colorStops 从内圆向外圆过渡。最常用的形态是同心扩散——两点重合、`StartRadius` 为 `0`，做出"中心亮、边缘暗"的球体或光晕；两点不重合则得到偏心高光。

```ts
const circle = new Konva.Circle({
  x: 120, y: 120, radius: 80,
  fillPriority: 'radial-gradient',
  fillRadialGradientStartPoint: { x: 0, y: 0 },   // 本地坐标：圆心
  fillRadialGradientStartRadius: 0,
  fillRadialGradientEndPoint: { x: 0, y: 0 },
  fillRadialGradientEndRadius: 80,                 // 等于圆半径，渐变铺满整个圆
  fillRadialGradientColorStops: [0, '#fde047', 0.5, '#f97316', 1, '#dc2626'],
});
```

把实例切到 `radial-gradient`，能看到中心黄、外缘红的同心扩散。通常 `EndRadius` 大于等于 `StartRadius`；若反过来，渐变方向也随之反转。

### 图案填充

图案填充把一张位图反复贴进形状：`fillPatternImage` 提供贴图，`fillPatternRepeat` 控制平铺方式（`'repeat'`、`'repeat-x'`、`'repeat-y'`、`'no-repeat'`，默认 `'repeat'`），`fillPatternOffset` / `OffsetX` / `OffsetY` 平移图案原点，`fillPatternScaleX` / `ScaleY` 缩放图案单元，`fillPatternRotation` 旋转（单位为度）。图案坐标同样在形状本地系。

```ts
const image = new Image();
image.src = '/textures/stripe.png';
image.onload = () => {
  // 图片必须解码完成后才能用作图案
  const rect = new Konva.Rect({
    x: 40, y: 40, width: 220, height: 120,
    fillPriority: 'pattern',
    fillPatternImage: image,
    fillPatternRepeat: 'repeat',     // 默认即 repeat，这里显式写出以表明意图
  });
  layer.add(rect);
  layer.batchDraw();
};
```

实例的图案源是用离屏 canvas 同步生成的对角条纹（见 `example.ts` 的 `createPatternSource`），省去了异步加载图片的处理。把 `fillPriority` 切到 `pattern`，即可看到条纹铺满六边形。若图案单元过大或过小，用 `fillPatternScaleX` / `ScaleY` 调整缩放。

## 最佳实践

- **始终显式声明 `fillPriority`。** 不要依赖回退兜底：形状同时有 `fill` 和渐变属性时，默认 `'color'` 会让纯色静默胜出。多写一行 `fillPriority: 'linear-gradient'`，就能省去"渐变为什么不显示"的排查。
- **图案优先用可同步生成的源。** `fillPatternImage` 接受 `HTMLImageElement`，但 `Image` 是异步的；若图案能由代码生成（条纹、棋盘、网格），用离屏 `HTMLCanvasElement` 同步生成可省去 `onload` 处理，创建形状时即可绘制。

## 常见问题

- 设了 `fillLinearGradientColorStops`，形状却不显示渐变？
  先查是否同时设了 `fill`（纯色）且 `fillPriority` 仍是默认 `'color'`——这种组合下纯色优先，渐变被忽略。显式 `shape.fillPriority('linear-gradient')` 即可。若完全没设 `fill` 颜色，回退兜底会自动选中渐变，但建议始终显式声明，避免歧义。
- `fillPatternImage` 设了却看不到图案？
  图片是异步加载的，必须在 `image.onload` 之后再把 `image` 赋给 `fillPatternImage`（或创建形状），否则 Konva 拿到的是未解码的图片。赋值后调用 `layer.batchDraw()` 重绘。
- 图案单元看起来太大或太小？
  用 `fillPatternScaleX` / `ScaleY` 缩放图案单元（值大于 `1` 放大、小于 `1` 缩小）。图案坐标在形状本地系，形状变大时图案单元不会自动跟着缩放，通常需要按形状尺寸同步调整 scale。

## 总结回顾

摘要：

Konva 的所有形状都能用线性渐变、径向渐变、图案三种填充，它们与纯色一起挂在 `Konva.Shape` 上。决定哪一套生效的总开关是 `fillPriority`，其默认值 `'color'` 是最大的坑——同时设了纯色与渐变却不显式声明时，纯色静默胜出。线性渐变由起点—终点连线定义方向，径向渐变由内圆—外圆定义扩散，图案由 `fillPatternImage` + `fillPatternRepeat`（默认 `'repeat'`）定义贴图；三者的坐标都在形状本地系，colorStops 统一用偏移、颜色交错数组。

一句话：

> `fillPriority` 决定四套填充谁生效——不显式声明时默认 `'color'`，会让渐变与图案静默失效。

知识要点：

- 一个形状能否同时携带多套填充数据？由谁决定当前用哪一套？
- `fillPriority` 的默认值是什么？同时设了纯色和渐变会发生什么？
- 线性渐变的方向由哪两个属性定义？坐标是绝对还是形状本地？
- 径向渐变的内圆、外圆分别由哪些属性定义？
- `fillPatternRepeat` 的默认值是什么？要调整图案单元大小用哪个属性？
