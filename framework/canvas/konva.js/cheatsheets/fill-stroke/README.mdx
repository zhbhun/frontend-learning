# 填充、描边与阴影

填充（fill）、描边（stroke）、虚线（dash）和阴影（shadow）是 Konva 里塑造形状外观的四组属性，它们全都挂在 `Konva.Shape` 上——矩形、圆、文本、路径等每一种形状都继承自它，所以这些属性在所有形状上用法一致。先建立一个判断就能预测大部分结果：**填充和描边是两条互不依赖的绘制通道**，你可以只填、只描、两者都要或都不要；虚线只改写描边的连续性，不影响填充；阴影则在所有启用的笔画外圈再叠一层投影。

每个属性都配一个 `*Enabled` 开关（`fillEnabled`、`strokeEnabled`、`dashEnabled`、`shadowEnabled`），它和颜色值本身是分离的——关掉开关，即使颜色还在，对应笔画也不画。这层分离是最容易被忽略、也最值得先记住的一点。下面的参考表列出核心属性及默认值（取自 Konva 源码 `Konva.Shape` 的 getter 默认值）。

| 属性 | 含义 | 默认值 | 不设会怎样 |
| --- | --- | --- | --- |
| `fill` | 填充颜色（CSS 字符串） | `undefined` | 不画填充 |
| `fillEnabled` | 是否绘制填充 | `true` | — |
| `stroke` | 描边颜色 | `undefined` | 不画描边 |
| `strokeWidth` | 描边宽度（像素） | `2` | — |
| `strokeEnabled` | 是否绘制描边 | `true` | — |
| `dash` | 虚线模式 `[线段, 间隔, ...]` | `undefined` | 实线 |
| `dashOffset` | 虚线整体平移 | `0` | 不偏移 |
| `dashEnabled` | 是否启用虚线 | `true` | — |
| `shadowColor` | 阴影颜色 | `undefined` | 不画阴影 |
| `shadowBlur` | 阴影模糊半径 | `0` | 硬边阴影 |
| `shadowOffsetX` / `shadowOffsetY` | 阴影偏移 | `0` / `0` | 不偏移 |
| `shadowOpacity` | 阴影不透明度 | `1` | — |
| `shadowEnabled` | 是否绘制阴影 | `true` | — |

默认值有两层语义要分清：`fill`、`stroke`、`shadowColor` 默认都是 `undefined`——也就是说**一个新建的形状默认既无填充、也无描边、更无阴影**，只有显式给了颜色才会画；而 `fillEnabled` / `strokeEnabled` / `shadowEnabled` 默认都是 `true`，意思是「只要你给了颜色，我就画」。

## 填充

填充用 `fill` 指定一个 CSS 颜色字符串（`'#4f7cff'`、`'rgb(255,0,0)'`、`'transparent'` 都可以），形状内部就按这个颜色填满。`fillEnabled` 是它的开关：设成 `false` 时，即便 `fill` 还有值，内部也留空。

```ts
const rect = new Konva.Rect({
  x: 20, y: 20, width: 120, height: 80,
  fill: '#4f7cff',          // 画蓝色填充
  // fillEnabled: false,    // 关掉后内部留空，即使 fill 仍有值
});
```

下面的实例把四组属性都接到控件上。先看填充：把「启用填充」关掉，矩形内部立刻变透明（露出底层画布），而描边还在——这就是「填充是一条独立通道」的直接证据。读数第一行同步显示当前生效的填充颜色或「关闭」。

填充还有两个属性留作回查：`fillRule`（填色规则，默认沿用 Canvas 的 `'nonzero'`，可设 `'evenodd'`，对自交路径有意义）和 `fillPriority`（多种填充并存时哪个生效，默认 `'color'`；线性 / 径向渐变与图案在「[渐变与图案](?path=/docs/gradients-patterns--docs)」一课展开）。纯色填充时这两个都不用动。

## 描边

描边用 `stroke` 指定颜色、`strokeWidth` 指定宽度（像素），形状轮廓就按这两个值绘制。与填充一样，`strokeEnabled` 是独立开关。`strokeWidth` 默认是 `2`，这也是为什么「只写 `stroke: 'black'`」就能看到一条 2px 的轮廓。

```ts
const rect = new Konva.Rect({
  x: 20, y: 20, width: 120, height: 80,
  stroke: '#0f172a',
  strokeWidth: 4,
  // strokeEnabled: false,   // 关掉后不画轮廓
});
```

在实例里关掉「启用描边」、只留填充，得到「无轮廓的纯色块」；反过来关掉填充、只留描边，得到「空心框」。两种状态对应同一组属性，差别只在开关——这是描边与填充相互独立的最直观证据。

一个需要单独记住的行为：`strokeWidth` 参与描边判定，**为 `0` 时 Konva 视为没有描边**（`hasStroke()` 要求 `strokeWidth()` 真值）。所以 `strokeWidth: 0` 和 `strokeEnabled: false` 效果一样，都不画轮廓。

描边默认**随形状缩放变粗**：`strokeScaleEnabled` 默认 `true`，`scale` 放大形状时描边也跟着变粗。若想保持描边粗细恒定（例如做图标库），把它设成 `false`。

Konva 默认的绘制顺序是**先填后描**：先画填充，再把描边盖在上面，所以你看到的描边是完整的 `strokeWidth` 宽。少数情况需要反过来（先描后填，让填充盖住描边内侧，视觉上描边只剩一半宽），把 `fillAfterStrokeEnabled` 设成 `true` 即可。

描边的端点和拐角由 Canvas 同名属性控制，Konva 未设时沿用 Canvas 上下文默认值：

| 属性 | 取值 | 默认（Canvas） | 何时相关 |
| --- | --- | --- | --- |
| `lineCap` | `'butt'` / `'round'` / `'square'` | `'butt'` | 开放路径（`Line`）的端点；闭合形状差异不明显 |
| `lineJoin` | `'miter'` / `'round'` / `'bevel'` | `'miter'` | 描边拐角，锐角处尤其明显 |
| `miterLimit` | 数值 | `10` | `lineJoin: 'miter'` 时限制尖角延伸，超过则转 `bevel` |

### 虚线

虚线由 `dash` 控制，它是一个「线段、间隔、线段、间隔……」交替的数组：`[10, 5]` 表示画 10px、空 5px；`[10, 5, 2, 5]` 则是「长划—间隔—点—间隔」的复合虚线。空数组或 `undefined` 都表示实线。`dashOffset`（默认 `0`）可把虚线图案整体平移，常用于做「蚂蚁线」流动动画——在动画循环里持续递增 `dashOffset` 即可。`dashEnabled`（默认 `true`）是开关。

```ts
const rect = new Konva.Rect({
  x: 20, y: 20, width: 120, height: 80,
  stroke: '#0f172a', strokeWidth: 3,
  dash: [10, 5],           // 虚线
  // dash: [10, 5, 2, 5],  // 长划 + 点的复合虚线
});
```

实例里切换「描边线型」，轮廓立刻在实线、虚线、点线、长划线之间变化，填充与阴影都不受影响——印证了 `dash` 只作用于描边这一条通道。读数「线型」会显示当前数组，方便核对。

## 阴影

阴影把最多参数捏在一起：`shadowColor` 是触发阴影的必要条件，`shadowBlur` 控制柔和程度（`0` 是硬边投影，越大越糊），`shadowOffsetX` / `shadowOffsetY` 让投影偏移方向，`shadowOpacity`（默认 `1`，范围 `0`–`1`）单独控制阴影透明度。`shadowEnabled` 是总开关。

一个关键判断：**只有 `shadowColor`（或 `shadowBlur` / `shadowOffset` 之一）被显式赋值，Konva 才认为这个形状「有阴影」**。源码里 `hasShadow()` 的判定是 `shadowEnabled && shadowOpacity !== 0 && (shadowColor || shadowBlur || shadowOffsetX || shadowOffsetY)`。所以最稳妥的做法是显式给 `shadowColor`；只写 `shadowBlur: 10` 不给颜色时，Konva 会 fallback 成黑色阴影。

```ts
const rect = new Konva.Rect({
  x: 20, y: 20, width: 120, height: 80,
  fill: '#4f7cff',
  shadowColor: '#000000',
  shadowBlur: 12,
  shadowOffsetX: 8,
  shadowOffsetY: 8,
  shadowOpacity: 0.6,
  // 也可用复合写法：shadowOffset: { x: 8, y: 8 },
});
```

实例里阴影默认是关着的（`shadowEnabled: false`），形状很干净。打开「启用阴影」，再分别调「阴影模糊」「阴影偏移 X/Y」，就能看到投影从硬边到柔和、从正下方到斜后方——读数「阴影」一行把当前参数原样回显。

还有一个与阴影质量相关的开关：当一个形状同时有填充和描边时，阴影会分别投在两次绘制上，可能在边缘出现「双重阴影」痕迹。`Konva.Shape` 的 `perfectDrawEnabled`（默认 `true`）会先把整个形状画到离屏画布再统一投阴影来规避这个瑕疵；`shadowForStrokeEnabled`（默认 `true`）控制描边是否参与投阴影，设成 `false` 则只有填充投阴影。多数情况两者都保持默认即可，只有在追求性能关闭 `perfectDrawEnabled` 时才需要留意这种叠加。

## 总结回顾

摘要：

填充、描边、虚线、阴影是 `Konva.Shape` 上的四组外观属性，所有形状用法一致。填充与描边是两条独立通道，各有颜色和 `*Enabled` 开关；`fill`、`stroke`、`shadowColor` 默认 `undefined`（不画），而各 `*Enabled` 默认 `true`（给了颜色就画）。虚线 `dash` 只改写描边的连续性，端点与拐角由 `lineCap` / `lineJoin` 控制。阴影由 `shadowColor` 触发，`shadowBlur` / `shadowOffset` / `shadowOpacity` 调节形态；默认绘制顺序是先填后描，描边完整可见。实例把四组属性都接到控件上，关掉任一开关就能看到对应笔画消失，读数把生效参数原样回显。

一句话：

> 填充与描边是两条互不依赖的绘制通道，各自的颜色和开关分离；虚线只作用于描边，阴影由 `shadowColor` 触发、独立于前三者。

知识要点：

- `fill`、`stroke`、`shadowColor` 的默认值是什么？不设会怎样？
- 关掉 `fillEnabled` 时，`fill` 的颜色值还在吗？
- `dash` 数组 `[10, 5]` 的两段分别代表什么？空数组表示什么？
- 要让阴影出现，最少要设哪个属性？
- 默认绘制顺序是先填还是先描？`fillAfterStrokeEnabled` 会怎样改变可见描边宽度？
