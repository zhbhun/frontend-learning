# 线、多边形与路径

矩形、圆、椭圆的形状由「尺寸」（宽高、半径）直接定义；本课的形状则由「几何数据」定义——你要么给出一组顶点，要么给出几个生成参数，要么写一段 SVG 路径字符串。按「几何怎么喂」来分类，是理解这一组形状最快的入口。

其中 `Konva.Line` 最特殊：它一个类承担了四种形态。同一组 `points`，只拨动 `closed` 和 `tension` 两个属性，就能在折线、样条曲线、多边形、闭合曲线之间切换；`Konva.Arrow` 是它的子类（Line + 箭头）。`Konva.RegularPolygon` 与 `Konva.Star` 走另一条路——你只给中心、半径和角数，顶点由 Konva 算。`Konva.Path` 又不同，它吃一整段 SVG 路径字符串 `data`。记住这条分类线，下面的属性表与实例都能提前预测结果。

五种形状的几何来源与定位参考点（共享默认值：`fill` 不设、`stroke` 不设、`strokeWidth` 为 `2`、`x`/`y` 为 `0`）：

| 形状 | 几何由什么定义 | `x`/`y` 指向 | 本课关键变化 |
| --- | --- | --- | --- |
| `Konva.Line` | `points` 顶点数组 | 相对父节点平移整条线 | `closed`、`tension`、`bezier` |
| `Konva.Arrow`（继承 Line） | `points` 顶点数组 | 同上 | `pointerLength`、`pointerWidth` |
| `Konva.RegularPolygon` | `sides` + `radius` | 中心 | `sides`（3=三角，6=六边…）、`cornerRadius` |
| `Konva.Star` | `numPoints` + `innerRadius` + `outerRadius` | 中心 | 内外径比（尖瘦↔饱满） |
| `Konva.Path` | `data`（SVG 路径字符串） | 平移整段路径 | 支持 M/L/C/Q/A/Z 等命令 |

## 线、折线与多边形

`Konva.Line` 用一个扁平的 `points` 数组 `[x1, y1, x2, y2, ...]` 定义几何——它是一维交替数组，不是 `[{x, y}]`，这是为了性能。线段按数组顺序连接。真正改变「形态」的只有三个属性：

- `closed`（默认 `false`）：是否把最后一个顶点连回第一个。设为 `true` 就成了多边形，并且 `fill` 才会生效——开放线在引擎层只描边、不填充。
- `tension`（默认 `0`）：在顶点之间做样条插值的张力。`0` = 直线段；`>0` = 平滑曲线穿过各顶点（需要至少 3 个顶点才能看出效果）。
- `bezier`（默认 `false`）：把 points 当作贝塞尔控制点绘制；与 `tension` 互斥，只在无 tension 时生效。

三者的组合让一个类覆盖四种用法：折线（都不开）、样条曲线（只开 `tension`）、多边形（只开 `closed`）、闭合曲线/blob（两个都开）。Konva 没有单独的 `Polygon` 类——多边形就是 `Konva.Line({ closed: true })`。

下面这个实例用同一组围绕椭圆分布的顶点，让你只拨动 `closed` 和 `tension` 就看到四种形态。每个顶点用小圆点标出，你会注意到 `tension` 只改变「顶点之间的连线」，顶点本身（`points` 数组）始终不动。

读数最后一行「形态」直接给出当前属于折线 / 样条曲线 / 多边形 / 闭合曲线中的哪一种——它完全由 `closed` 与 `tension` 派生，`points` 数组始终是几何的真源。四种形态的最小写法：

```ts
// 折线：开放、直线段
const line = new Konva.Line({
  points: [20, 80, 80, 20, 140, 80, 200, 20],
  stroke: '#4f7cff',
  strokeWidth: 3,
  lineCap: 'round',
  lineJoin: 'round',
});

// 多边形：closed: true 即可填充（Konva 没有单独的 Polygon 类）
const polygon = new Konva.Line({
  points: [100, 20, 180, 80, 140, 160, 60, 160, 20, 80],
  closed: true,
  fill: 'rgba(79, 124, 255, 0.2)',
  stroke: '#4f7cff',
  strokeWidth: 2,
});

// 样条曲线：tension > 0 平滑穿过各点
const spline = new Konva.Line({
  points: [20, 80, 80, 20, 140, 80, 200, 20],
  tension: 0.5,
  stroke: '#4f7cff',
  strokeWidth: 3,
});

// blob：闭合 + tension
const blob = new Konva.Line({
  points: [100, 20, 180, 80, 140, 160, 60, 160, 20, 80],
  closed: true,
  tension: 0.5,
  fill: 'rgba(79, 124, 255, 0.2)',
  stroke: '#4f7cff',
  strokeWidth: 2,
});

layer.add(line, polygon, spline, blob);
```

注意 `Konva.Line` 没有默认描边：忘记设 `stroke`（配合 `strokeWidth`，默认 `2`），线段什么都不画——这与矩形忘记 `fill`/`stroke` 一样无声。`lineCap`（默认 `butt`）和 `lineJoin`（默认 `miter`）控制端点与拐角样式；想要圆头线段就把 `lineCap` 设为 `round`。`dash`、`shadow*` 等描边相关属性在「[填充、描边与阴影](?path=/docs/fill-stroke--docs)」统一讲，这里不展开。

### 箭头

`Konva.Arrow` 继承自 `Konva.Line`，所以 `points`、`tension`、`dash` 等全部沿用；它额外在端点画一个箭头三角。箭头由四个属性控制：

- `pointerLength`（默认 `10`）：箭头尖端沿线条方向的长度。
- `pointerWidth`（默认 `10`）：箭头底部的宽度。
- `pointerAtBeginning`（默认 `false`）：是否在起点也画箭头。
- `pointerAtEnding`（默认 `true`）：是否在终点画箭头。

```ts
// 直线箭头
const arrow = new Konva.Arrow({
  points: [40, 120, 240, 120],
  pointerLength: 12,
  pointerWidth: 12,
  stroke: '#1e293b',
  strokeWidth: 3,
  fill: '#1e293b', // 箭头三角的填充：通常和 stroke 同色
});

// 弯曲箭头：tension 同样生效
const curved = new Konva.Arrow({
  points: [40, 60, 120, 20, 200, 60, 260, 40],
  tension: 0.5,
  pointerLength: 10,
  pointerWidth: 10,
  stroke: '#4f7cff',
  strokeWidth: 3,
  fill: '#4f7cff',
});
```

箭头三角是填充图形，颜色取自 `fill`，而线条取自 `stroke`——想让箭头整体同色，就把两者设成一样。`points` 至少需要两组坐标（起点、终点），否则没有可画的线条。

## 正多边形与星形

`Konva.RegularPolygon` 和 `Konva.Star` 走的是参数化路线：你不用逐个列顶点，只给「中心 + 半径 + 数量」，顶点由 Konva 按规则均匀生成。两者都继承自 `Konva.Shape`，`x`/`y` 指向中心，填充、描边等能力与其它形状一致。

### 正多边形

`Konva.RegularPolygon` 用 `sides` 和 `radius` 定义：`sides` 是边数（3 = 三角形、4 = 正方形、5 = 五边形、6 = 六边形……），`radius` 是中心到顶点的距离。`cornerRadius`（默认 `0`）可给正多边形圆角，单值统一，也可传数组按顶点单独控制。

```ts
// 六边形
const hexagon = new Konva.RegularPolygon({
  x: 120,
  y: 100, // 中心
  sides: 6,
  radius: 70,
  fill: '#4f7cff',
  stroke: '#1e293b',
  strokeWidth: 2,
});

// 三角形 + 圆角
const triangle = new Konva.RegularPolygon({
  x: 280,
  y: 100,
  sides: 3,
  radius: 70,
  cornerRadius: 10,
  fill: 'rgba(79, 124, 255, 0.3)',
});
```

`sides` 和 `radius` 没有有用的默认值，不设会得到一个不可见的退化形状，创建时必须给出。

### 星形

`Konva.Star` 用三个属性定义：`numPoints`（尖角数）、`outerRadius`（外径，中心到外顶点）、`innerRadius`（内径，中心到内顶点）。外径与内径的比值决定星的「性格」——`innerRadius` 接近 `outerRadius` 时星接近饱满的多边形；`innerRadius` 远小于 `outerRadius` 时星变得尖锐。

```ts
// 经典五角星
const star = new Konva.Star({
  x: 120,
  y: 110, // 中心
  numPoints: 5,
  innerRadius: 30,
  outerRadius: 70,
  fill: '#facc15',
  stroke: '#1e293b',
  strokeWidth: 2,
});

// 饱满星：内径接近外径
const puffy = new Konva.Star({
  x: 280,
  y: 110,
  numPoints: 6,
  innerRadius: 55,
  outerRadius: 70,
  fill: 'rgba(79, 124, 255, 0.4)',
});
```

三个属性同样没有有用的默认值，必须显式给出。想让星绕中心旋转，用 `rotation`（度数）即可——因为 `x`/`y` 已经是中心，旋转轴心天然正确。

## 路径

`Konva.Path` 接受一段 SVG 路径字符串 `data`，按 SVG 路径语法绘制任意形状。它是本课唯一「声明式」的形状——你不操作顶点数组，而是写路径命令。`x`/`y` 平移整段路径（路径坐标本身写在 `data` 里）。

```ts
const heart = new Konva.Path({
  x: 40,
  y: 40,
  data: 'M 50,80 C 50,40 0,40 0,80 C 0,120 50,150 50,150 C 50,150 100,120 100,80 C 100,40 50,40 50,80 Z',
  fill: '#ef4444',
  stroke: '#1e293b',
  strokeWidth: 2,
});
```

`data` 支持标准 SVG 路径命令（大写绝对坐标、小写相对坐标）：

| 命令 | 含义 | 命令 | 含义 |
| --- | --- | --- | --- |
| `M` / `m` | 移动到（起点） | `Q` / `q` | 二次贝塞尔 |
| `L` / `l` | 直线到 | `T` / `t` | 平滑二次贝塞尔 |
| `H` / `h` | 水平线到 | `C` / `c` | 三次贝塞尔 |
| `V` / `v` | 垂直线到 | `S` / `s` | 平滑三次贝塞尔 |
| `A` / `a` | 圆弧 | `Z` / `z` | 闭合路径 |

`Konva.Path` 还提供两个实用方法：`data(data)` 读取或替换路径字符串，`getPointAtLength(length)` 返回路径上指定距离处的坐标点（配合 `getLength()` 可做沿路径动画）。形状一旦超出「点数组」或「几个参数」能方便表达的复杂度（心形、箭头图标、地图轮廓），`Path` 通常是更省事的选择。

## 总结回顾

摘要：

本课的形状按「几何怎么喂」分三类。`Konva.Line` 用一维 `points` 数组定义顶点，靠 `closed` 与 `tension` 在折线、样条曲线、多边形、闭合曲线之间切换——Konva 没有单独的 Polygon 类，多边形就是闭合的 Line，且只有闭合才填充。`Konva.Arrow` 继承 Line，在端点加由 `pointerLength`/`pointerWidth` 控制的箭头三角，颜色取自 `fill`。`Konva.RegularPolygon` 与 `Konva.Star` 走参数化路线，给中心、半径和数量即可，顶点由 Konva 生成。`Konva.Path` 吃一段 SVG 路径字符串 `data`，适合点数组难以表达的复杂轮廓。实例用同一组围绕椭圆分布的顶点演示了 Line 的四种形态，顶点小圆点证实了「tension 只插值、points 才是真源」。

一句话：

> `Konva.Line` 一个类靠 `closed` 和 `tension` 覆盖线、样条、多边形、blob 四种形态；其余形状的区别在几何怎么给——点数组、参数，还是 SVG 路径字符串。

知识要点：

- 同一组 `points`，拨动 `closed` 和 `tension` 会得到哪四种形态？
- 为什么开放线设置了 `fill` 也不显示？
- `Konva.Arrow` 的箭头三角颜色由哪个属性决定？
- `Konva.RegularPolygon` 与 `Konva.Star` 的几何分别由哪些属性定义？`x`/`y` 指向哪里？
- `Konva.Path` 的几何来自哪个属性？它支持哪种路径命令语法？
