# 矩形、圆与椭圆

矩形、圆和椭圆是 Konva 里最常被首先用到的三种几何形状。它们都继承自 `Konva.Shape`，因此填充、描边、阴影、变换等能力完全一致——这些共享能力在「[填充、描边与阴影](?path=/docs/fill-stroke--docs)」一课展开。本课只聚焦三者各自的「尺寸怎么定义」和「x/y 指向哪里」，因为正是这两点决定了：同一个坐标，会画出位置完全不同的图形。

三者最值得先建立的直觉是**定位参考点**：矩形的 `x`/`y` 是它的左上角，圆与椭圆的 `x`/`y` 是它们的中心。所以当你把三种形状放在同一个 `x` 上，矩形会从该点向右延伸，圆与椭圆会以该点为中心向两侧展开。记住这一点，下面的属性表与实例操作都能提前预测结果。

三者各自的尺寸属性与定位参考点（共享默认值：`fill` 不设、`stroke` 不设、`strokeWidth` 为 `2`、`x`/`y` 为 `0`）：

| 形状 | 定义尺寸的属性 | `x`/`y` 指向 | 不设尺寸时 |
| --- | --- | --- | --- |
| `Konva.Rect` | `width`、`height` | 左上角 | 默认 `0`，画不出图形 |
| `Konva.Circle` | `radius` | 中心 | 默认 `0`，画不出图形 |
| `Konva.Ellipse` | `radiusX`、`radiusY`（或复合写法 `radius: { x, y }`） | 中心 | 默认 `0`，画不出图形 |

## 创建与定位

三种形状的创建套路一致：`new Konva.X({ ...属性 })` 得到节点，再 `layer.add(node)` 把它挂到某个 Layer 上即可渲染。Stage 与 Layer 的搭建流程见「[安装与第一个场景](?path=/docs/first-scene--docs)」与「[核心架构](?path=/docs/architecture--docs)」，这里直接聚焦形状本身。

下面这个实例把三种形状放在**同一个 `x`** 上，用一条竖直参考线标出这个共用坐标，并在每种形状的定位参考点上放一个小圆点。拖动「位置 x」控件，就能直接看到「角定位」与「中心定位」的差别。

读数最能说明问题：同一个 `x` 值，矩形的水平范围是 `[x, x+width]`（从 `x` 起），圆与椭圆的水平范围是 `[x-r, x+r]`（以 `x` 为中心）。把「位置 x」调到同一个数，三行的起始值不同，定位语义的差异就摆在了面前。

### 矩形

`Konva.Rect` 用 `width` 和 `height` 定义尺寸，`x`/`y` 是左上角。`cornerRadius` 控制圆角，可传单个数值（四角统一），也可传四元数组 `[topLeft, topRight, bottomRight, bottomLeft]` 单独控制每个角；默认 `0`。

```ts
const rect = new Konva.Rect({
  x: 20,        // 左上角
  y: 20,
  width: 120,
  height: 80,
  cornerRadius: 12,           // 四角统一
  // cornerRadius: [12, 0, 12, 0], // 仅左上、右下圆角
  fill: '#4f7cff',
  stroke: '#1e293b',
  strokeWidth: 2,
});
layer.add(rect);
```

实例中矩形的定位点（小圆点）落在它的左上角、贴着参考线——这正是「角定位」的可观察证据。注意 `width`/`height` 默认为 `0`，忘记设置不会报错，但什么都画不出来。

### 圆

`Konva.Circle` 只用一个 `radius` 定义尺寸，`x`/`y` 是**圆心**。它的 `width`/`height` 是由半径派生出来的（`getWidth()` 返回 `radius * 2`），所以日常只调 `radius`。`radius` 默认为 `0`，不设同样画不出图形。

```ts
const circle = new Konva.Circle({
  x: 100,       // 圆心
  y: 100,
  radius: 50,
  fill: '#4f7cff',
  stroke: '#1e293b',
  strokeWidth: 2,
});
layer.add(circle);
```

实例中圆的定位点落在它的圆心上、压住参考线，因此整圆跨在线的两侧——这与矩形「形体全在线右侧」形成对照。

### 椭圆

`Konva.Ellipse` 用 `radiusX` 和 `radiusY` 分别定义横向与纵向半径，`x`/`y` 是**中心**。两个半径独立，所以能画出压扁或拉长的椭圆；也可以用复合写法 `radius: { x, y }` 代替。`radiusX`/`radiusY` 默认都为 `0`。

```ts
const ellipse = new Konva.Ellipse({
  x: 100,        // 中心
  y: 100,
  radiusX: 60,
  radiusY: 35,
  // 等价写法：radius: { x: 60, y: 35 },
  fill: '#4f7cff',
});
layer.add(ellipse);
```

实例中分别拖动「椭圆 radiusX」与「椭圆 radiusY」，可以看到横向、纵向半径互不影响——这是椭圆区别于圆（`radius` 单一）的关键。定位点同样落在中心、压住参考线。

## 总结回顾

摘要：

矩形、圆、椭圆都继承自 `Konva.Shape`，创建套路一致（`new Konva.X({...})` 后 `layer.add(...)`），共享的填充、描边、阴影、变换能力不在本课展开。三者的差异集中在两点：尺寸由什么定义（矩形是宽高、圆是单一半径、椭圆是两个独立半径），以及 `x`/`y` 指向哪里（矩形是左上角、圆与椭圆是中心）。实例把三者放在同一个 `x` 上，用参考线和定位点直观区分了「角定位」与「中心定位」，读数里的水平范围进一步把差别量化出来。

一句话：

> 矩形的 `x`/`y` 落在左上角，圆与椭圆的 `x`/`y` 落在中心——同一个坐标，三种语义。

知识要点：

- 哪个属性分别决定矩形、圆、椭圆的尺寸？
- `x`/`y` 对三种形状各指什么位置？
- `cornerRadius` 接受哪两种形式？
- 圆与椭圆不设半径时会出现什么？默认值是多少？
