# 学习笔记：Phaser

## 偏好
- 主题边界：仅 Phaser 4（当前稳定线 v4.2.x）；不写 3.x 对照，存量 3.x 教程不作为课程参考。
- 进阶边界：纳入性能优化与生产构建、Phaser Editor / Launcher、原生平台打包发布（Capacitor 等跨平台工具链）。
- 示例语言：TypeScript；示例为嵌入 Storybook Canvas 的可运行 Phaser 实例，复用工作区共享 canvas / readout / source helper。
- 教程正文、说明与界面文案用中文；路径、命令、包名、API 与代码标识符保留英文。
- 节奏按长期系统学习设计，课程同时支撑顺读与回查。

## 工作笔记
- 官方 API 文档在 docs.phaser.io（随版本更新）；示例库主入口 phaser.io/examples，labs.phaser.io 为 Phaser 4 专用示例浏览器。
- 原生打包（Capacitor 等）、Phaser Editor v5 等依赖外部工具链或订阅产品的主题，以其自身官方文档作为课程级参考资料，不在 RESOURCES.md 收录。
- 工作区 tutorials/ 目录中的教程资料基于 Phaser 3，与已确认版本边界不符，课程不引用。
