# Transformers.js

- [@官方@Transformers.js 官方文档](https://huggingface.co/docs/transformers.js)
  覆盖：快速上手、任务与模型支持范围、教程、开发者指南（WebGPU、量化、自定义模型等）和完整 API 参考。适用于：所有课程的第一手依据，与库版本同步维护。
- [@官方@huggingface/transformers.js 源码仓库](https://github.com/huggingface/transformers.js)
  覆盖：源码、Releases 更新日志和 GitHub Issues。适用于：确认版本行为变化（尤其 v3→v4）、排查具体版本问题、跟踪新模型支持。
- [@官方@transformers.js-examples 官方示例仓库](https://github.com/huggingface/transformers.js-examples)
  覆盖：60+ 官方示例应用——WebGPU 聊天、分割、背景移除、Node/Bun/Deno 用法、Next.js/SvelteKit 模板等。适用于：工程化与任务实战阶段的完整应用参考。
- [@官方@npm 包 @huggingface/transformers](https://www.npmjs.com/package/@huggingface/transformers)
  覆盖：最新发布版本、运行时要求和依赖（onnxruntime-web / onnxruntime-node）。适用于：安装与环境确认。
- [@官方@兼容模型目录](https://huggingface.co/models?library=transformers.js)
  覆盖：Hub 上带 transformers.js 标签的可用模型列表。适用于：各任务课程挑选示例模型与查找能力对应的架构。
