# yjs

- [@官方@Yjs 官方站点](https://yjs.dev)
  覆盖:项目门户,生态与托管服务入口。适用于:建立对 yjs 定位与生态版图的直觉。
- [@官方@Yjs 官方文档](https://docs.yjs.dev)
  覆盖:快速上手、API(Y.Doc、共享类型、Document Updates、UndoManager、RelativePosition、Awareness、Subdocuments、Internals)、生态 Provider 与官方教程。适用于:整条学习路线的主要依据,各课程参考资料的第一来源。
- [@开源@yjs/yjs 官方仓库](https://github.com/yjs/yjs)
  覆盖:源码、README、发布记录与 issue 讨论。适用于:核对行为细节、确认版本变化与边界行为。
- [@开源@yjs-demos 官方示例集合](https://github.com/yjs/yjs-demos)
  覆盖:各编辑器绑定与 Provider 组合的可运行示例。适用于:同步、编辑器绑定课程的范例参照。
- [@开源@crdt-benchmarks](https://github.com/dmonad/crdt-benchmarks)
  覆盖:主流 CRDT 实现的性能基准与测试方法。适用于:性能与基准课程。

## 社区

- [Yjs 官方论坛](https://discuss.yjs.dev)
  适用于:现实反馈、用法求证与维护者答疑;课程中存疑行为的第一求证渠道。

## 工具

- [@开源@y-sweet](https://github.com/jamsocket/y-sweet)
  覆盖:托管与自托管的 yjs 服务端,含客户端 SDK 与本地开发 CLI。适用于:y-sweet 课程;tester/ 项目实际使用的服务端。
- [@官方@Hocuspocus 文档](https://tiptap.dev/docs/hocuspocus)
  覆盖:插件化 yjs 服务端的鉴权、持久化、webhook 与扩展机制。适用于:Hocuspocus 课程。
- [@开源@yhub](https://github.com/yjs/yhub)
  覆盖:yjs 官方新一代生产级服务端(Node.js 实现,Rust/yrs 绑定为实验项;y-redis 重写线的收编)。适用于:yhub 课程。
