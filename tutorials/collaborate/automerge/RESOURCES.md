# Automerge

- [@官方@Automerge 官网](https://automerge.org/)
  覆盖：项目总入口，含社区、博客与团队信息。适用于：全程。
- [@官方@Automerge 文档](https://automerge.org/docs/hello/)
  覆盖：官方手册——文档模型（values、list、text、counters、conflicts、rich text）、Repo 层（DocHandle、存储、网络、临时数据）、cookbook 与迁移指南。适用于：全部课程的第一手依据。
- [@开源@automerge 主仓库](https://github.com/automerge/automerge)
  覆盖：Rust 核心 + WASM JS 绑定源码、变更日志与发布。适用于：核对 API 行为、追踪版本变化。
- [@开源@automerge-repo 仓库](https://github.com/automerge/automerge-repo)
  覆盖：同步层 monorepo——websocket/IndexedDB 等适配器、React/Svelte/Solid 绑定。适用于：同步与集成阶段的课程。
- [@官方@官方博客](https://automerge.org/blog/)
  覆盖：Automerge 3、automerge-repo 2 等关键版本的发布公告与设计说明。适用于：建立版本意识与迁移专题。
